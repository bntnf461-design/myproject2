作業要領書 音声メモ（VOICE_MEMO.html）

スマホのレコーダーで話した作業手順を、番号付きの手順に整えて、
Word や Excel にそのままドラッグ＆ドロップするためのページです。
インストール不要・登録不要・インターネット不要。
VOICE_MEMO.html をダブルクリックして、Edge（または Chrome）で開くだけで使えます。

■ みんなに配る方法
  ・VOICE_MEMO.html（この1ファイルだけ）を、社内の共有フォルダーに置く。
    各自がダブルクリックで開くか、自分のデスクトップにコピーして使います。
  ・メールで .html の添付がブロックされる場合は、共有フォルダーか Teams のファイルで渡してください。
  ・Claude などのアカウントは要りません。外部のサーバーにも一切つながりません
    （入力した文章はそのパソコンのブラウザの中だけで処理されます）。
  ・スマホ側は、もともと入っているレコーダー（ボイスメモ）とメールだけで使えます。

■ 使い方
  1. スマホのレコーダーで、作業手順を話して録音し、文字起こしする
       iPhone  ：ボイスメモ → 録音を開く → 文字起こしを表示 →「…」からコピー（iOS 18 以降）
       Pixel   ：レコーダー →「文字起こし」タブ → 共有 → テキスト
       Galaxy  ：ボイスレコーダー →「文字起こし」→ 長押しでコピー
       文字起こしが無い時は、キーボードのマイクで直接このページに話しても入力できます。
  2. 文章を会社のパソコンへ送る
       ・自分の会社アドレスにメールで送る（いちばん簡単）
       ・Teams の自分とのチャットに貼り付ける
       ・Android で .txt に保存した場合は、ファイルを入力枠へドロップできます
     どの方法が使えるかは会社のルールに従ってください。
  3. 入力枠に貼り付けて「手順に整える」
       ・「えー」「あのー」などを消します
       ・「まず」「次に」「それから」「最後に」などの所で手順を分けます
       ・「注意」「ポイント」で始まる文は、1つ前の手順の安全・品質ポイントにします
       ・レコーダーの時刻（00:12）や「話者 1」も消します
     安全・品質のポイントは、下の「安全・品質のポイント」枠に1行に1つずつ入れると、
     いちばん関係する手順に自動で割り振ります（例：「パッキンも新品に替える」→「新しいフィルターに交換」の手順）。
       ・行の先頭に「安全」「品質」と書くと、その種類になります
       ・書かなければ言葉から判断します（保護具・電源・挟まれ…は安全、トルク・寸法・確認・新品…は品質）
       ・どの手順にも合わないものは「共通」の行に入ります
  4. 右側の青い札をつかんで、Word / Excel にドロップ
       「Word へ」 ：番号付きの文章（【安全】【品質】つき）
       「Excel へ」：No・作業内容・安全ポイント・品質ポイント の表（1手順＝1行）
       表の番号（青い四角）をつかむと、その手順だけドラッグできます。
     ドロップがうまく入らない時は「Word 用にコピー」「Excel 用にコピー」で貼り付けてください。

■ 作業要領書（Excel）に書き込む
  右下の「作業要領書（Excel）に書き込む」で、会社の作業要領書の形の Excel ファイルを作ります。
    ・工程名・作業名称（部品名）・ページ（1/2 など）を書き込みます
    ・手順は「要素作業手順」、安全・品質ポイントは「急所ポイント」の欄へ
    ・安全ポイントの行には赤い十字、品質ポイントの行には黄色のひし形の印を付けます
    ・長い文は次の行に続けて書きます（番号は最初の行だけ）
    ・1枚（10行）に入りきらない時はシート「２」「３」…を増やします。1つの手順がページをまたがないようにします
    ・「作業全体（共通）」のポイントは一番上の行に入ります
  ひな形：
    ・「入っているひな形」… 作業要領書の空の形（写真・手順は空）がこのファイルに入っています
    ・「自分のひな形」… 会社の .xlsx を選ぶと、その形に書き込みます
       （見出しの「要素作業手順」「急所ポイント」と、その下の結合したセルを目印にしています。
         写真や図解はそのまま残ります。図解Ｎｏ．の欄は空にします）
  印刷：
    ・「印刷範囲を全体に直して、1ページに収める」（はじめからオン）で、印刷範囲を
      表・図解の枠・改訂欄まで含む全体に広げ、各シートが A4 横 1 枚に収まるように設定します
    ・ひな形の印刷範囲をそのまま使いたい時は、チェックを外してください
  図解の写真：
    ・「写真を追加」で選ぶ（スマホではその場で撮影）、枠へドロップ、Ctrl＋V で貼り付けのどれでも追加できます
    ・写真ごとに「どの手順の図解か」を選びます（追加した時は、写真の無い手順に順に割り当てます）
    ・写真は番号（①②…）の順に図解の枠へ入り、その手順の「図解Ｎｏ．」に番号が入ります
    ・写真は枠に合わせて縮めます。縦横の比率は変えません。大きなスマホ写真も小さくしてから入れます
    ・7枚を超えると次のシートへ続きます（枠の番号も ⑧⑨… に書き換えます）
    ・自分のひな形に前の写真や赤丸が入っていても、新しい写真を入れる枠の中身は消してから入れます
    ・写真はこのブラウザの中に残ります（「消す」を押すと消えます）
  このファイルの中だけで作るので、文章が外に送られることはありません（新しい Edge / Chrome が必要です）。

■ Claude で要約・割り振り（Claude を使える人だけ）
  話し言葉を作業要領書らしい短い文に直し、ポイントを手順に割り振ってもらえます。
  文の終わり（〜する。／〜します。）や、足りないポイントの【提案】も選べます。
    1.「頼む文をコピー」を押す
    2. Claude（claude.ai やアプリ）に貼り付けて送る
    3. 返ってきた答えを全部コピーして「答えを読み込む」
  claude.ai の中でこのページを開いた時は「Claude で整える」ボタン1つで済みます。
  Claude を使わない人は、これまでどおり「手順に整える」だけで作れます。
  ※ 会社のルールで社外に出せない情報は Claude に貼り付けないでください。

■ 手直し
  ・表の文章はクリックしてそのまま直せます。
  ・ポイントもクリックして直せます。別の手順に移す時は、文字を切り取って貼り付けます。
  ・↑↓ や番号のドラッグで並べ替え、× で削除。
  ・入力中の内容はそのブラウザに自動で残ります。
