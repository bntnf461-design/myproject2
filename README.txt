日報スキャン取り込み v1

スキャナー（サンワサプライ製など）で読み込んだ紙を、
  1) 日付ごとのフォルダに整理して保管し
  2) 紙に書かれた文字を読み取り
  3) Excel に1行ずつ自動で書き込む
ためのツールです。作業日報・硝子のロットNoの紙・検査シート（B5／A4）に対応します。
Windows 10・11 の標準機能だけで動きます（追加のインストールは不要。書き込みに Excel を使います）。

■ はじめに（最初の1回だけ）
  1. このフォルダ（ダウンロードしたファイル一式）を、パソコンの好きな場所にコピーします。
  2. START_DAILY_REPORT.bat をダブルクリックして起動します。
     はじめて起動すると、ドキュメントの中に次のフォルダが作られます。
       ドキュメント\日報スキャン\受付   … スキャナーの保存先にするフォルダ
       ドキュメント\日報スキャン\保管   … 日付ごとに整理して保管する場所
       ドキュメント\日報スキャン\日報データ.xlsx … 読み取った内容を書き込む Excel
     （場所は「設定」で変えられます。共有フォルダ（NAS）にもできます）
  3. スキャナーのソフト（サンワサプライの付属ソフトなど）で、保存先を「受付」フォルダにします。
     ・保存形式は JPEG（.jpg）がおすすめです（PDF・PNG・TIFF も可）。
     ・解像度は 300dpi、カラーかグレーがおすすめです（文字の読み取りがよくなります）。
     ・「1枚ずつ別のファイルにする」設定にしてください。
     ※ 本体に microSD へ保存するタイプのハンディスキャナーの場合は、
       画面の「ファイルを追加…」でカードの画像を選ぶと、受付フォルダにコピーされます。

■ 毎日の使い方
  1. 同じ種類の紙をまとめてスキャンします（日報だけ → ロットの紙だけ → 検査シートだけ）。
     スキャンした紙は、画面左の一覧に自動で出てきます。
  2. 画面上の「日報の日付」を選びます（翌朝にまとめてスキャンする時は「昨日」）。
  3. 「紙の種類」を選びます（日報／ロット表／検査シート）。
  4. 「取り込む（保管＋読み取り）」を押します（F5 キーでも可）。
     ・左の一覧でチェックした紙だけ取り込みます。チェックが無い時は、全部取り込みます。
     ・紙の画像は次の場所に移して保管します（受付フォルダからは無くなります）。
         保管\2026\2026-11\2026-11-06\日報\2026-11-06_日報_01.jpg
         保管\2026\2026-11\2026-11-06\ロット表\2026-11-06_ロット表_01.jpg
         保管\2026\2026-11\2026-11-06\検査シート\2026-11-06_検査シート_01.jpg
       読み取った文字は、同じ名前の .txt にも残します（あとから探す時に便利です）。
  5. 右の表に読み取った内容が出ます。間違いがあれば、表のマスを直接直してください。
     （行をダブルクリックすると、その紙の画像が開きます）
  6. 「Excelに書き込む」を押します（F8 キーでも可）。
     ・Excel の「日報」「ロット」などのシートに1枚＝1行で追加されます。
     ・列：日付／読み取った項目／スキャン画像（押すと紙の画像が開く）／取り込み日時
     ・同じ内容を、その日の保管フォルダの「読み取り結果_日報.csv」にも控えとして残します。
     ・Excel ファイルを誰かが開いている時は書き込めません。閉じてから、もう一度押してください
       （表の内容は消えません）。

  ほかのボタン
    「この日の保管フォルダ」… 選んでいる日付のフォルダを開きます
    「Excelを開く」       … 日報データ.xlsx を開きます

■ 文字の読み取り方法（「設定」で選びます）
  ● Windows 標準（はじめはこちら）
    ・無料。インターネットは不要。紙の画像が外に出ることはありません。
    ・印刷された文字や、ていねいな字はよく読めますが、手書きの字は間違いが多めです。
    ・紙に印刷されている見出し（「目印の文字」。例：品番、生産数）を探し、その右の文字
      （右に無ければ下の行）を読み取ります。設定の「目印の文字」を、お使いの日報の
      見出しと同じ言葉にしてください。
    ・日本語の「光学式文字認識（OCR）」が必要です。読めないと出た時は、Windows の
      「設定」→「時刻と言語」→「言語と地域」→ 日本語 →「言語のオプション」で追加してください。
  ● Claude（手書きの日報向け）
    ・手書きの字や、表の形の日報もよく読めます。紙のどこに何が書いてあっても読み取れます。
    ・インターネットが必要です。紙の画像を Anthropic 社のサーバーに送って読み取ります
      （社内のきまりで外に出してよいか、事前に確認してください）。
    ・Anthropic の APIキーが必要です（https://console.anthropic.com で作成。使った分だけの
      支払いで、紙1枚あたり数円程度です）。キーはこのパソコン・このユーザーでしか
      読めない形で暗号化して保存します。
    ・設定の「Claude への説明」に、その項目が何か（例：使用した硝子のロット番号）を書くと、
      読み取りの精度が上がります。

■ 読み取る項目を変える（設定 → 紙の種類）
  ・紙の種類ごとに、Excel に書く項目（列）を自由に足したり消したりできます。
  ・「複数」にチェックすると、同じ項目が何か所にあっても全部読み取ります（ロットNoなど）。
  ・「形の決まり」に正規表現を書くと、目印に関係なく、その形の文字を全部拾います。
      例）ロットNo が「A2611-01」のような形なら   [A-Z]\d{4}-\d{2}
  ・「文字を読み取って Excel に書く」を外すと、その種類は保管だけ行います
    （はじめは検査シートが保管だけになっています）。
  ・項目を増やしても、Excel の列は見出しの名前で合わせるので、今までの行はずれません。

■ ファイル
  DailyReport.ps1               本体
  START_DAILY_REPORT.bat        起動用（これをダブルクリック）
  START_DAILY_REPORT_DEBUG.bat  画面が出ない時の確認用（エラーが黒い画面に出ます）
  dailyreport_settings.json     設定（自動で作られます）
  dailyreport_error.log         エラーの記録（うまくいかない時に確認）
  tests\test_dailyreport.ps1    動作確認のテスト
                                （powershell -ExecutionPolicy Bypass -File tests\test_dailyreport.ps1）
