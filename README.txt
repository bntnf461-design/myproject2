NG MONITOR v67 - 消失検知（色が消えたらNG）対応

【今回の追加】
今まで「指定した色が出たらNG」の判定だけでしたが、①の検出設定に
「検知の条件」を追加し、エリアごとに次のどちらかを選べるように
しました。

  ・色が出たらNG（点灯・混入検知）……今までの動作（初期値）
  ・色が消えたらNG（部品なし検知）……指定した色が消えたらNG

使い方：
  一覧からエリアを選び、「検知の条件」で該当する方を選ぶだけです。
  「NG検知の割合」スライダーの意味も条件に応じて自動で変わります
  （出た時＝この値以上でNG／消えた時＝この値を下回ったらNG）。

  例：部品が正しく取り付けられていれば見える色のシールなどを

NG MONITOR v61 - バグ修正版（複数エリア機能の検証）

前回追加した「複数エリア監視」機能を中心に検証し、実際に見つかった

1. 【設定の保存に関する不整合】「設定を保存する」で任意の場所
