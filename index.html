事務所との共有

計画・品目・実績・設定をまとめて1つのファイルに保存／復元します。

品目の登録

品目ごとに「1個あたりの時間」を登録します。計画カレンダーで品目を呼び出して、ラインごとに作る順番を組みます。現時点目標・差異・進捗率・終了時間は品目の時間で計算します。

品目名1個あたりの時間（秒）
品目は Excel の雛形（「品目」シート）からもまとめて登録できます。

作業開始時刻

作業開始時刻：

作業開始前の終了時間は「作業開始時刻 ＋ 計画数量 × 1個あたりの時間 ＋ 休憩」で表示します。自動開始にすると、この時刻に自動で作業開始します。開始時刻より後に画面を開いた場合も、この時刻から作業していたものとして計算します。手動で「作業開始」を押した日は自動開始しません。

休憩時間

開始終了
休憩中は目標が増えず、終了時間の計算でも休憩分を除外します。

使い方（説明書）

1. 画面の見かた

品目今作っている品目。下の小さい字は「何品目め／全品目数」「今の品目の終了見込み」「次の品目と数量」。
品目は1日に複数登録でき、上から順番に作ります。全部作り終えると「完了」になります。
計画数量今の品目の計画数量（小数も可。例：10.5）。
現時点目標今の品目で、今の時刻までに作り終えているべき数。
前の品目が実際に終わった時刻から数えます（休憩・一時停止中は増えません）。前の品目が遅れても、次の品目の目標は自動で後ろにずれます。
実績数量今の品目でテンキーを押して数えた数。
差異／進捗率実績 − 現時点目標（不足は ▲）／ 実績 ÷ 現時点目標。
状況 100%以上 ／ 90〜99.9% ／ 90%未満（90%未満は稼働中に点滅）。色は設定で変更できます。
終了時間大きい数字：そのラインの全品目が終わる見込み時刻（休憩を含む）。
作業開始前は「作業開始時刻 ＋ 各品目の数量 × 1個あたりの時間」、開始後は今の遅れ・進みを含めて自動で更新します。
小さい「計画」：遅れがない場合の当初の終了時刻。
合計全ライン・全品目の計画数量・現時点目標・実績の合計。

1-2. 本日の計画（📋 本日）

  • 「📋 本日」ボタン（またはテンキー ＋）で、今日の計画を1画面で確認できます。もう一度押すとアンドン表示に戻ります。
  • タイムライン：ラインごとに、品目を作る順番・開始〜終了時刻を帯で表示します。斜線は休憩、赤い縦線は現在時刻です。
  • 稼働中は、完了した品目は灰色、作業中の品目は青い枠（青い部分が進み具合）で表示し、遅れた分だけ後ろの品目もずれます。帯の下の細い線は当初の計画です。
  • 一覧表：品目ごとの数量・1個あたりの時間・所要時間・開始／終了時刻・遅れを表示します。
  • 「◀ 前の日／次の日 ▶」で、カレンダーに入力した他の日の計画も確認できます。「🖨 印刷」で紙に印刷できます。
  • 事務所からは http://現場PCの名前:8080/#plan を開くと、最初からこの画面で表示されます。

2. 準備（最初に1回）

  1. 「⚙ 設定」でライン数（4ライン・5ラインなど）を選びます。
  2. 「品目の登録」で、品目名と「1個あたりの時間（秒）」を登録します（Excel の「品目」シートからも登録できます）。
  3. 作業開始時刻と休憩時間を入力します。毎日決まった時刻に始めるなら「自動で作業開始する」にチェックを入れます。
  4. 必要に応じて、キーの割り当て・行の色・状況の色を変えて「保存」します。

3. 計画の入力

  • カレンダーで入力：「📅 計画」を押し、日付をクリック → ラインごとに「＋ 品目を追加」で品目を呼び出し、数量を入れます。作る順番は ▲▼ で並べ替えます。最後に「保存」。
  • 「前日の計画をコピー」「この計画を今月の平日すべてに入れる」でまとめて入力できます。
  • 当日に数量だけ直す：表の計画数量をクリックするか、テンキー ＊ → 数字（小数点は .）→ Enter。今の品目の数量が変わります。

3-2. Excel から取り込む

  1. 「📅 計画」で取り込みたい月を表示し、「📄 雛形をダウンロード」を押します（今のライン名・品目・日付が入った Excel ファイルができます）。
  2. 「品目」シートに品目名と1個あたりの時間（秒）を入力します。
  3. 「計画」シートに「日付・ライン・品目・計画数量」を1行ずつ入力します。同じ日・同じラインで複数の品目を作るときは、作る順番に行を並べます（行は挿入して増やせます。日付を省略すると上の行と同じ日）。
  4. 「📥 Excelから取り込み」でそのファイルを選び、内容を確認して「OK」→「保存」を押します。

読み込めるのは .xlsx と .csv です。ファイルに入っている日の計画は、全ラインともファイルの内容に置き換わります。入力ミス（未登録の品目・数字以外・マイナスなど）がある行は取り込まず、行番号を表示します。前の形式（A列：日付、B列以降：ラインごとの数量）の雛形も取り込めます。

4. 毎日の操作（テンキー）

作業開始・一時停止・再開Enter（押すたびに切り替わります。自動開始なら押さなくても始まります）
1個できたそのラインのキー：1=A 2=B 3=C 4=D 5=E …（初期設定）
実績は計画数量までしか増えません。計画数量が小数（例：10.5）のときは、10 の次に押すと 10.5 になって完了します。
計画数量に達すると、次に押した分から次の品目を数えます。
押し間違えた（−1）− を押してから、そのラインのキー（最後に数えた品目から取り消します。端数で増えた分は端数だけ戻ります）
計画数量の入力＊ → 数字 → Enter（. で小数点、− で1文字消す）
リセット／ を3秒以内に2回
本日の計画を表示＋（もう一度押すとアンドン表示に戻る）

複数のラインで同時に押しても、それぞれ数えます。テンキーを複数台つなぐ場合は、ラインごとに別のキーを割り当ててください（どの機器から押したかはブラウザで区別できません）。

5. 自動でリセットされるもの

  • 24時を過ぎると、実績・作業時間・計画数量がすべてリセットされ、新しい日の計画がカレンダーから読み込まれます。
  • 「リセット」ボタン／／×2 では、実績と作業時間を消去します（計画と設定は残ります）。

6. 事務所との共有（社内LAN）

現場PCを「サーバー役」にすると、事務所などの PC のブラウザから同じ画面を開いて、見たり変更したりできます（計画・品目・設定・実績の修正・作業開始など、現場と同じ操作ができます）。変更は約2秒で全部の画面に反映されます。

  1. 現場PC（最初に1回）：アンドンのフォルダー（index.html・andon-server.ps1 と .bat ファイル）を現場PCに置きます。
  2. setup-firewall.bat を右クリック →「管理者として実行」（事務所からつなげるようにする設定。最初に1回だけ）。会社のルールで実行できない場合は、システム担当者に「TCP 8080番の受信許可」を依頼してください。
  3. start-server.bat をダブルクリック。黒い画面（サーバー）が開き、ブラウザでアンドンが開きます。黒い画面は閉じないでください（最小化は可）。
  4. 毎朝自動で起動したいときは register-startup.bat をダブルクリック（Windows にサインインすると自動で起動します）。
  5. 事務所PC：ブラウザで http://現場PCの名前:8080/ を開きます（正しいアドレスは「⚙ 設定 → 事務所との共有」に表示されます）。ブックマークしておくと便利です。
  • これまでのデータを引き継ぐ：前に index.html を直接開いて使っていた場合は、そちらの画面で「⚙ 設定 → 💾 データを書き出す」→ サーバーの画面で「📂 データを読み込む」。
  • 画面上部の ● 共有中 がつながっている印です。● サーバー未接続 のときもその PC で操作はでき、つながった時に自動で合わせます。
  • 現場と事務所で同時に変更しても、両方の変更が残るように自動で合わせます（同じラインを両方で数えた場合は両方の数を足します）。
  • データは現場PCの andon-data.json に保存され、backup フォルダーに1日1回コピーが残ります（60日分）。
  • 現場PCがスリープすると事務所から見られなくなります。Windows の電源設定で「スリープしない」にしてください。

7. 困ったとき

  • テンキーを押しても数えない：画面下にオレンジ色の帯が出ていたら、画面をクリックしてください。作業開始前は数えません（「作業開始」を押してください）。計画数量に達した品目は、それ以上数えません。
  • 画面がはみ出す：「⛶ 全画面」を押すか F11 キーで全画面にしてください。文字の大きさは自動で調整されます。
  • データの保存：ファイルを直接開いた場合は、このパソコンのブラウザに保存されます。共有サーバーを使う場合は現場PCの andon-data.json に保存されます（6. 参照）。
  • 事務所から開けない：現場PCで start-server.bat の黒い画面が開いているか、setup-firewall.bat を実行したか、現場PCがスリープしていないかを確認してください。名前で開けない場合は、黒い画面に表示される http://数字:8080/ のアドレスを使ってください。
