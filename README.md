# ライン進捗アンドン

テンキーで各ラインの実績（Act）をカウントし、差異・進捗率・状況・終了時間を自動で更新するアンドン画面です。
`index.html` をブラウザ（Chrome / Edge）で開くだけで動きます。インストールやインターネット接続は不要です。
事務所の PC からも見たり変更したりする場合は、下の「事務所との共有」の手順で現場PCをサーバー役にします。

詳しい使い方は、画面右上の **「？ 使い方」**（説明書）で確認できます。説明書は「🖨 印刷」で紙に印刷できます。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| `index.html` | アンドン本体（画面） |
| `andon-server.ps1` | 事務所と共有するためのサーバー（Windows 標準の PowerShell で動作） |
| `start-server.bat` | サーバーを起動して画面を開く（ダブルクリック） |
| `setup-firewall.bat` | 事務所からつなげるようにする設定（最初に1回・管理者として実行） |
| `register-startup.bat` | Windows のサインイン時にサーバーを自動起動する |
| `計画取込テンプレート.xlsx` | Excel 取り込み用の雛形 |

## 事務所との共有（社内LAN）

現場PCを「サーバー役」にすると、事務所などの PC のブラウザから同じ画面を開いて、見たり変更したりできます。
計画・品目・設定の変更、実績の修正、作業開始など、現場と同じ操作ができ、変更は約2秒で全部の画面に反映されます。
追加のソフトやインターネット接続は不要です。

1. **現場PC**：このフォルダー一式を現場PCに置きます。
2. `setup-firewall.bat` を右クリック →「管理者として実行」（最初に1回）。
   実行できない場合は、システム担当者に「TCP 8080 番の受信許可（ドメイン／プライベート）」を依頼してください。
3. `start-server.bat` をダブルクリック。黒い画面（サーバー）が開き、ブラウザで `http://localhost:8080/` が開きます。**黒い画面は閉じないでください**（最小化は可）。
4. 毎朝自動で起動するには `register-startup.bat` をダブルクリック。
5. **事務所PC**：ブラウザで `http://現場PCの名前:8080/` を開きます。正しいアドレスは黒い画面と「⚙ 設定 → 事務所との共有」に表示されます。

- **これまでのデータを引き継ぐ**：前に `index.html` を直接開いて使っていた場合は、その画面で「⚙ 設定 → 💾 データを書き出す」→ サーバーの画面で「📂 データを読み込む」。
- 画面上部の **● 共有中** がつながっている印です。**● サーバー未接続** でもその PC で操作でき、つながった時に自動で合わせます。
- 現場と事務所で同時に変更しても、両方の変更が残るように自動で合わせます（同じラインを両方で数えた場合は両方の数を足します）。
- データは現場PCの `andon-data.json` に保存され、`backup` フォルダーに1日1回コピーが残ります（60日分）。
- 現場PCがスリープすると事務所から見られなくなります。電源設定で「スリープしない」にしてください。
- サーバーを使わずに `index.html` を直接開くと、これまでどおりその PC だけで動きます。

## 本日の計画（📋 本日）

「📋 本日」ボタン（またはテンキー ＋）で、今日の計画を1画面で確認できます。

- **タイムライン**：ラインごとに品目の順番・開始〜終了時刻を帯で表示（休憩は斜線、現在時刻は赤線）。
  稼働中は完了＝灰色、作業中＝青枠（進み具合つき）で表示し、遅れた分は後ろの品目もずれます。帯の下の細線は当初の計画です。
- **一覧表**：品目ごとの数量・1個あたりの時間・所要時間・開始／終了・遅れ。
- 「◀ 前の日／次の日 ▶」で他の日の計画も確認でき、「🖨 印刷」で印刷できます。
- 事務所からは `http://現場PCの名前:8080/#plan` を開くと、最初からこの画面になります。

## 準備（最初に1回）

「⚙ 設定」で次の項目を決めます。

- ライン数（1〜8。4 ライン・5 ラインの運用に対応）、ライン名、+1 キー、行の色
- **品目の登録**：品目名と 1個あたりの時間（単位は 秒・分・時間 から選択。例：2 と「時間」で 1個あたり2時間）
- 作業開始時刻（「自動で作業開始する」にチェックを入れると、毎日その時刻に自動で開始）
- 休憩時間（複数登録できます）
- 状況（●）の色、操作キー

## 計画の入力（品目と順番）

1日に1ラインで複数の品目を作れます。品目は上から順番に作ります。

- **カレンダーで入力**：「📅 計画」→ 日付をクリック → ラインごとに「＋ 品目を追加」で登録した品目を呼び出し、計画数量を入力（小数も可）。▲▼ で順番を入れ替えます。
- **当日に数量だけ直す**：表の計画数量をクリックするか、テンキー ＊ → 数字（. で小数点）→ Enter。今の品目の数量が変わります。
- **Excel から取り込む**：下の「Excel から取り込む」を参照。

## Excel から取り込む

1. 「📅 計画」で取り込みたい月を表示し、**「📄 雛形をダウンロード」** を押します。今のライン名・品目・日付が入った Excel ファイル（`plan_年-月.xlsx`）ができます。
   - リポジトリの `計画取込テンプレート.xlsx` は A〜E ラインの雛形（2026年11月・品目は未登録）です。
2. 「品目」シートに品目名・1個あたりの時間・単位（秒／分／時間）を入力します（単位が空欄なら秒）。
3. 「計画」シートに1行ずつ入力して保存します。

   | 日付 | ライン | 品目 | 計画数量 |
   |---|---|---|---|
   | 2026/11/02 | A | 品目X | 120 |
   |  | A | 品目Y | 80.5 |
   | 2026/11/02 | B | 品目X | 200 |

   - 同じ日・同じラインで複数の品目を作るときは、作る順番に行を並べます（行は挿入して増やせます。日付を省略すると上の行と同じ日）。
   - 品目を空欄にすると、ラインの「品目なしの時の時間」で計算します。数量が空欄の行は取り込みません。
4. **「📥 Excelから取り込み」** でそのファイルを選び、確認画面で「OK」→ カレンダーの「保存」を押します。

- 読み込めるのは **.xlsx** と **.csv**（UTF-8 / Shift_JIS）です。古い .xls は「.xlsx」で保存し直してください。
- ファイルに入っている日の計画は、全ラインともファイルの内容に置き換わります。「品目」シートの品目は追加・更新されます。
- 未登録の品目・数字以外・マイナス・読めない日付がある行は取り込まず、行番号を表示します。
- 前の形式（A列：日付、B列以降：ラインごとの数量）のファイルも取り込めます（品目なし）。

## テンキー操作（初期設定）

| キー | 動作 |
|---|---|
| 1〜5 | ライン A〜E の実績 +1（今の品目の計画数量まで） |
| − → ラインのキー | そのラインの実績 −1（入力ミスの取消） |
| Enter | 作業開始 → 一時停止 → 再開 |
| ＊ | 計画数量の入力（数字＋Enter で次のラインへ、. で小数点、− で1文字消す） |
| ／ を2回（3秒以内） | リセット |
| ＋ | 本日の計画の表示／アンドン表示に戻る |

- 実績は今の品目の **計画数量までしか増えません**。計画数量が小数（例：10.5）のときは、10 の次に押すと 10.5 になって完了します。
- 品目が計画数量に達すると、次に押した分から **次の品目** を数えます。
- −1 は最後に数えた品目から取り消します（前の品目に戻ることもあります）。

キーの割り当ては設定画面で変更できます。どのラインのキーも同時に受け付けるので、複数ラインで同時に入力できます。
ブラウザではキーボードごとの区別ができないため、テンキーを複数台つなぐ場合は、ラインごとに別のキーを割り当ててください。

## 計算方法

- **現時点目標**（今の品目）= 前の品目が実際に終わった時刻（1品目めは作業開始）からの実稼働時間 ÷ その品目の 1個あたりの時間
  - 小数点以下は切り捨て、計画数量が上限。休憩時間と一時停止中の時間は含めません。
  - 前の品目が遅れると、次の品目の目標・終了時間も自動で後ろへずれます。
- **差異** = 実績 − 現時点目標（不足分は ▲ で表示）
- **進捗率** = 実績 ÷ 現時点目標
- **状況**：🟢 100%以上 / 🟠 90〜99.9% / 🔴 90%未満
- **終了時間** = そのラインの全品目が終わる見込み時刻（休憩を含む）
  - 作業開始前：作業開始時刻 ＋ Σ（計画数量 × 1個あたりの時間）
  - 作業開始後：今の品目の残り × 時間 ＋ 次以降の品目の時間（今の遅れ・進みを含む）。翌日になる場合は「翌」を付けます。
  - 下の小さい「計画」は、遅れがない場合の当初の終了時刻です。

## 前日の残りの持ち越し

24時を過ぎたとき、前日に終わらなかった品目の残り（計画 − 実績）があると、翌日の画面に確認が出ます。

- テンキー **Enter で持ち越し**、**− で持ち越さない**。品目ごとのチェックや「本日の計画の前（先に作る）／後」も選べます。
- 持ち越した品目には「↻」と元の日付（例：10/30の残り）が付きます。数え始めた品目があるラインでは、その後ろに入ります。
- あとからでも「📋 本日」の「↻ 前日の残りを持ち越す」で持ち越せます。休みの日をはさんでも次の日に持ち越せます。
- 「⚙ 設定 → 前日の残りの持ち越し」で「毎回確認する／自動で持ち越す／持ち越さない」を選べます。
- 共有中は、どの PC で選んでも全部の画面に反映されます（二重に持ち越されることはありません）。

## リセット

- **24時を過ぎると**、実績・作業時間・計画がすべてリセットされ、新しい日の計画がカレンダーから読み込まれます（未入力の日は計画なし）。前日に終わらなかった分は持ち越せます（上記）。
- **リセット** ボタン（またはテンキー ／ ×2）では、実績と作業時間を消去します（計画と設定は残ります）。

データは、共有サーバーを使う場合は現場PCの `andon-data.json`、`index.html` を直接開いた場合はその PC のブラウザに保存されます。どちらも画面を再読み込みしても残ります。前のバージョンのデータは自動で新しい形式に変換されます。
「⚙ 設定 → 💾 データを書き出す／📂 データを読み込む」で、全データのバックアップと復元ができます。
