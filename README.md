# 作業要領書テンプレート（動画再生付き）

作業要領書の「手順」や「急所」をタップすると、その部分の動画が再生されるテンプレートです。
どの工場・どの作業でも使えるように、**中身（データ）と画面（仕組み）を分けて** 作っています。

- **インストール不要**：フォルダをコピーして `index.html`（メニュー）をブラウザ（Chrome / Edge）で開くだけ
- **完全オフライン**：閲覧・動画再生・作成・保存まで、インターネットに一切つながずに使えます（外部サービス・外部ライブラリ・Web フォントを使っていません）。USB メモリや社内の共有フォルダに置いてそのまま使えます
- **低スペック PC でも軽い**：動画はタップした時だけ読み込み、閉じたら解放。動画プレーヤーは 1 つを使い回します。重いアニメーションや画像効果は使っていません
- **紺 × 白** の見やすい配色。ボタンは手袋でも押しやすい大きさ
- **パソコン・タブレット・スマホ** に対応（狭い画面ではカード表示に切り替わります）
- **印刷** にも対応（A4 横。紙の要領書としても使えます）

## 画面の作り

| 画面 | 形 | 内容 |
|---|---|---|
| ホーム・一覧・作成・取り込み・撮り方・設定 | 左にメニュー（スマホは下のタブ） | どの画面にもすぐ移れる。ホームでは登録件数・動画がまだの件数・最近の更新が分かる |
| 要領書を開いたとき | 帳票型（社内の要領書と同じ見た目） | 作業要領書・管理番号・承認欄・NO.｜手順｜✚◆｜急所 の並び。行をタップで動画。印刷すると紙の要領書に |
| 「▶ 手順を順に見る」 | 現場タブレット型 | 1 画面に 1 手順を大きく。何番目か・進み具合を表示。大きな「前へ／再生／次へ」 |

## フォルダ構成

```
index.html         … メニュー（最初に開く画面。はじめての方への流れも表示）
list.html          … 要領書の一覧（ライン・製品・工程で絞り込み・検索）
manual.html        … 要領書の表示・動画再生
editor.html        … 要領書の作成・編集（入力画面）
manuals/
  catalog.js       … 一覧に出す要領書の目録と設定（設定画面から編集）
  sample-001.js    … 要領書データ（1 要領書 = 1 ファイル）
videos/            … 動画ファイルを入れる
images/            … 写真・図を入れる
guide.html         … 撮影ガイド（スマホの設定・PC の画面録画）
settings.html      … 設定（工場名・カテゴリーの編集）
bulk.html          … Excel まとめて取り込み
samples/           … Excel 取り込みの見本
assets/            … 画面の仕組み（通常は触らなくて OK）
```

## 作業者用のかんたん画面（PC が苦手な方向け）

`easy.html` は、大きなボタンを押していくだけ（例：**ライン → 工程 → 作業**）で要領書が開く画面です。選ぶものが 1 つしか無い段は自動で飛ばします。

- ボタンの段（ライン・製品・工程・作業区分）と順番・表示名は、設定画面の「**一覧・かんたん画面で選ぶ項目**」で変えられます。ボタンの並び順は「カテゴリーの名前」の順番です
- ホームの「**この PC を作業者用にする**」を押すと、その PC では index.html を開いても、かんたん画面が出ます（編集のボタンも出ません）。戻すときは、かんたん画面の下の「リーダー・管理者の方へ」→「作業者用をやめる」
- デスクトップにアイコンを作る方法は、撮影ガイドの「**デスクトップから 1 回で開く**」にあります
- どの画面にも「**？ 困ったとき**」ボタンがあり、その画面でよくある困りごとと直し方が出ます

## 使い方（見る人）

1. `index.html`（メニュー）で「**要領書を見る**」を押し、**ライン → 製品 → 工程** の順にタップして絞り込み、要領書を選ぶ
   - 数字はその条件で見つかる要領書の件数。もう一度タップすると解除
   - 検索欄に文書番号や作業名を入れて探すこともできます
   - 要領書を見て一覧に戻ると、前の絞り込みのまま表示されます
   - 検索は手順・急所の文字も対象です（「トルク」「保存ボタン」などでも探せます）
   - 「最近見た要領書」から、よく見る要領書をすぐ開けます
   - 30 日以内に作られた・改訂された要領書には「新規」「改訂」の印が付きます
   - 「**動画がまだの手順がある**」「**見直し時期（1 年以上 改訂なし）**」のボタンで、すぐ絞り込めます（見直し時期の要領書には赤い印）
   - 「**⇩ 台帳を Excel で書き出す**」で、表示している要領書の一覧（管理番号・改訂・改訂日・動画の数・見直し時期など）を Excel で開けるファイルにします
2. 手順の行、または「▶ 動画」ボタンをタップすると動画が再生されます
3. 「▶」マークの付いた急所は、その急所だけの動画が再生されます
4. 動画が無い手順も、行をタップすると手順を大きく表示します
5. 「**▶ 手順を 1 つずつ見る**」で、すべての手順を大きな画面で順に確認できます（動画の無い手順は写真や説明を大きく表示。→ キーで次へ）
6. 写真はタップすると拡大表示されます

動画画面の操作：

| ボタン | キーボード | 内容 |
|---|---|---|
| ◀ 前へ ／ 次へ ▶ | ← / → | 前・次の手順の動画へ |
| ⟲ 最初から | Home | その手順の最初から再生 |
| ▶ 再生 / ❚❚ 停止 | Space | 再生・一時停止 |
| 0.5倍 / 0.75倍 / 標準 | | スロー再生（新人教育向け） |
| ↻ 繰り返し | R | その手順を繰り返し再生 |
| ⏭ 続けて再生 | A | 終わったら次の手順へ自動で進む（全手順の通し再生・教育用） |
| ✕ 閉じる | Esc | 要領書に戻る |

「文字 大」で文字を大きくできます（設定は PC ごとに保存されます）。

## 使い方（作る人）

### 1. 要領書を作る

1. `editor.html` を開く（一覧の「＋ 新規作成」、または表示画面の「編集」）
2. 文書情報・準備・手順・急所を入力
   - **動画は「🎬 動画を手順に分ける」がいちばん簡単です**（下の「動画を手順に分ける」を参照）
   - 手順ごとに付ける場合は「選ぶ」でファイルを選択 →「区間を設定」で動画を見ながら **開始・終了位置** をボタンで指定できます
   - 1 本の長い動画を、手順ごとに区間で分けて使えます（動画を手順ごとに切り分ける必要はありません）
   - 「＋ 手順を追加」すると、前の手順と同じ動画が入り、**前の手順の「終了」が新しい手順の「開始」** に自動で入ります。「終了」を決めたときも、次の手順の「開始」に自動で入ります。つまり、動画を見ながら区切りで「終了」を押していくだけで区間分けができます
   - 時間の書き間違い（終了が開始より前など）は保存時に教えてくれます
3. 「プレビュー」で表示を確認
4. 「**フォルダに保存**」を押し、このテンプレートのフォルダ（`index.html` があるフォルダ）を選ぶ
   - 要領書ファイルの保存、一覧（`catalog.js`）への追加、選んだ動画・写真の `videos` / `images` へのコピーを **まとめて自動で** 行います
   - 初回だけ「このフォルダへの書き込みを許可しますか」と聞かれるので「許可」を選びます。フォルダは記憶されるので、2 回目からは選び直す必要はありません
   - **Ctrl + S** でも保存できます。画面下に「● 未保存の変更あり」／「保存済み」が表示されます
   - Chrome / Edge で使えます

入力途中の内容は自動保存されるので、画面を閉じても続きから再開できます。

便利な機能：

| 機能 | 内容 |
|---|---|
| ＋ 下に追加 | 手順の途中に手順を追加（動画は前の手順の続きから） |
| 複製して新規 | 似た作業の要領書を、今の内容をひな形にして作る |
| ＋ 改訂する | 改訂番号を 1 つ上げ、改訂日を今日にして、改訂履歴に行を追加。承認・点検・確認の判子を外すかも選べます。**改訂する前の文を覚えておき、作業者の画面で変わったところに黄色の印**と「改訂」の印を付けます（手順を並べ替えただけのところには付きません） |
| 別の人の保存に気づく | 共有フォルダで、開いた後に別の PC でその要領書が保存されていたら、上書きする前に知らせます（上書きした場合も前の内容はバックアップに残ります） |
| 自動バックアップ | 「フォルダに保存」で上書きする前の内容を `manuals/_backup` に日時付きで残す（間違えて保存しても戻せる） |
| この要領書を削除する | 一覧から外し、ファイルを `manuals/_trash` に移す（動画・写真は残る） |

バックアップやゴミ箱から戻すときは、`_backup`／`_trash` のファイルを `manuals` に戻して元の名前に変え、エディタで開いて「フォルダに保存」してください（一覧への追加も自動で行われます）。

### かんたん入力

エディタは、はじめは「**かんたん入力**」（① 作業の名前 → ② 手順を 1 つずつ → ③ 仕上げ）で開きます。上の切り替えで「すべての項目」（1 画面で全部）にもできます。どちらで入力しても同じ要領書です。

手順ごとに「**見せ方**」を選べます：🎬 **動画**（動きが大事な作業）／🖼 **写真**（場所・向き・見た目が大事）／📝 **文字だけ**。写真・文字だけにした手順は「動画がまだ」に数えず、作業者の画面では写真（無ければ文字）を大きく表示します。「すべての項目」では「この手順は動画を使わない」のチェックで同じことができます。

### 動画を手順に分ける（1 本撮りの動画を見ながら区切るだけ）

作業を最初から最後まで 1 本で撮った動画を、手順ごとの区間に分けます。動画ファイルを切ったり書き出したりはしない（開始・終了の時間を記録するだけ）ので、PC の性能に左右されず、すぐ終わります。

1. エディタの「**🎬 動画を手順に分ける**」を押し、「別の動画を選ぶ」で撮った動画を選ぶ
2. ▶ 再生し、手順が終わったところで「**✂ ここまでが「手順 1」**」（**Enter キー**）を押す。押すたびに次の手順へ進みます
3. 手順の間に使わない部分があるときは、次の手順の始まりで「**⇤ ここから開始**」（**S キー**）
4. 区切りの線はタイムライン上で**ドラッグして前後に調整**できます。右の一覧の ▶ でその区間だけ再生して確認
5. 「**この区切りで反映する**」→「フォルダに保存」

| 操作 | キー |
|---|---|
| 再生／一時停止 | Space |
| 区切って次の手順へ | Enter |
| ここから開始 | S |
| 1 秒戻る／進む（Shift で 5 秒） | ← → |
| 元に戻す | Ctrl + Z |

2 倍速で見ながら区切ることもできます。区切りは 0.1 秒単位で記録されます。

「写真の無い手順に、動画の場面を写真として付ける」にチェックが入っていると、各手順の始まりの場面を自動で写真にします（印刷や一覧の見出し画像に使われます）。

### インドネシア語に翻訳する（日本語で確認してから使う）

1. エディタの「**🌐 インドネシア語**」→「**🌐 まとめて翻訳**」
   - Chrome（バージョン 138 以降）の**端末内の翻訳**を使います。最初の 1 回だけ翻訳のデータをダウンロードするためインターネットが必要で、その後はインターネット無しで翻訳できます
2. 1 行ずつ「日本語（元の文）｜インドネシア語｜**日本語に戻すと**」が並びます。インドネシア語を日本語に戻した文を読んで、意味が合っていれば「**確認OK**」
   - 言葉がおかしいときは、インドネシア語の欄を直接直すか、「📖 用語集」に決まった訳語を登録して「翻訳し直す」
   - 「確認がまだのものだけ表示」で、残りだけを見られます
3. 「フォルダに保存」

| 機能 | 内容 |
|---|---|
| 用語集 | 「急所 → poin kunci」のように決めた訳語は、どの要領書でも必ずその言葉で訳す（`catalog.js` の `glossary`）。「よく使う言葉を追加」で候補を入れられます（会社の言い方に合わせて直してください） |
| 日本語が変わったとき | 翻訳した後で日本語を直すと「日本語が変わりました」と表示され、作業者の画面では古い訳を出さずに日本語を表示します |
| CSV に書き出す／読み込む | 自動翻訳が使えない PC や、インドネシア語が分かる人に見てもらうときに。Excel で「インドネシア語」の列を直し、確認した行に OK と入れて読み込みます |

### 読み上げ

「▶ 順に見る」の画面の「**🔈 読み上げ：オフ**」（V キー）を押して「オン」にすると、手順・急所・理由を声で読み上げます。次の手順に進むたびに自動で読みます。はじめはオフで、一度オン（またはオフ）にすると、その PC ではそのままになります。インドネシア語の表示にしているときはインドネシア語で読みます。

- PC に入っている音声を使うので、インターネットは要りません。インドネシア語の声は、Windows の「設定 → 時刻と言語 → 音声」でインドネシア語の音声を追加すると使えます
- **自然な声**：設定画面の「読み上げ」で「インターネットにつながっているときは、自然な声を使う」にチェックすると、Edge の自然な声（Nanami・Gadis など）で、人に近い抑揚で読みます。つながっていないときは自動で PC に入っている声に戻ります。言語ごとに声を選んで「▶ 声を試す」で聞き比べられます
- 読み間違える言葉は、設定画面の「**読み方の辞書**」に、ひらがなで読み方を登録します（例：仮締め → かりじめ）
- 読み上げている間は、動画の音を消します

作業者の画面（要領書）では、右上の「**🌐 Bahasa Indonesia**」を押すだけで切り替わります。インドネシア語の下に日本語が小さく出るので、リーダーも同じ画面で確認できます。日本語での確認がまだの訳には「※」が付きます。

### Excel で作った要領書を取り込む

今まで Excel で作ってきた要領書は、入力し直さずに取り込めます。

1. エディタの「**Excel 取り込み**」→「Excel ファイルを選ぶ」で `.xlsx` を選ぶ
2. 「主なステップ」「急所」「理由」などの見出しを自動で探して読み取ります。結果が画面に表示されるので確認する
   - 違っていたら「見出しの行」や各列を選び直す（下に Excel の中身が表示されるので、それを見ながら選べます）
   - シートが複数ある場合は「シート」で切り替え
3. 「この内容で取り込む」→ 動画を付けて「フォルダに保存」

自動で読み取るもの：

| 項目 | 読み取り方 |
|---|---|
| 手順・急所・理由・標準時間・区分 | 見出しの文字（例：主なステップ／作業内容、急所／ポイント、急所の理由、標準時間(秒)、区分）で判断 |
| 文書番号・作業名・工程・品番・制定日・改訂 など | 見出しより上の欄から、項目名の右（または下）の値を読む。「品番：AB-1」のような書き方にも対応 |
| 承認・点検・確認・作成 | 項目名の下の名前。下の欄に置いた**判子の画像**（貼り付けた画像・「セルに配置」した画像）は画像のまま、図形（〇と文字）の判子は文字を名前として読み取ります |
| 保護具・治工具・注意事項 | 項目名の右の値（改行や「、」区切りで複数） |
| 結合セル・セル内の改行 | 結合した手順の範囲の急所はまとめて 1 手順に。セル内で改行した急所・理由は 1 つずつに分けて対応させる |
| 【安全】【品質】 | 急所の先頭に付いていれば区分として取り込む |
| 貼り付けた写真 | 各手順の行にある最初の 1 枚を、その手順の写真に（保存時に images フォルダへ書き出し） |
| 動画 | 動画の列の「pack.mp4 0:00-0:10」のような書き方や、動画ファイルへのリンク |
| 改訂履歴 | 手順の下にある「改訂履歴」の表 |

- 古い形式（.xls）は、Excel で「名前を付けて保存」→「Excel ブック (.xlsx)」で保存し直してから取り込んでください

#### 様式を覚えさせる（自動で読み取れない社内様式）

見出しの名前が独特で自動で読み取れない様式でも、1 回だけ列の対応を直して「**この様式を覚える**」を押せば、次からは同じ様式の Excel を**自動でその対応で**読み取ります（1 件ずつの取り込みでも、まとめて取り込みでも）。覚えた様式は設定画面の「覚えた Excel の様式」で確認・削除できます。

#### まとめて取り込む（一気に取り込み）

一覧の「**Excel 取り込み**」（`bulk.html`）で、たくさんの Excel を一度に取り込めます。

1. 「Excel ファイルを選ぶ（複数可）」または「フォルダごと選ぶ」（ドラッグ＆ドロップも可）
2. 読み取り結果の一覧を確認（「内容」で手順を確認できます。取り込まないものはチェックを外す）
3. 「選んだ要領書をフォルダに保存」→ すべて保存され、一覧にも追加されます

- 1 つのファイルにシートが複数ある場合は、シートごとに 1 つの要領書になります（手順の無いシートは飛ばします）
- **登録済み**の要領書（同じ管理番号、または同じ作業名・工程）は、初期状態では取り込みません。Excel を直したので入れ直したい場合は「登録済みの要領書も上書きする」にチェック（前の内容はバックアップし、設定した動画は引き継ぎます）
- 同じ Excel を 2 回選んだ場合は「重複」として 1 つだけ取り込みます
- Excel を開いているときにできる一時ファイル（`~$` で始まるファイル）は自動で除きます
- 動画は取り込んだ後、一覧から要領書を開いて「編集」で付けます

#### 社内フォーマット（要素作業手順・急所ポイント 形式）への対応

要領書の画面は社内フォーマットと同じ並び（**No. ｜ 要素作業手順 ｜ ✚◆ ｜ 急所ポイント**）で表示します。

| Excel の書き方 | 取り込み後 |
|---|---|
| 「ＮＯ．」「要素作業手順」「急所ポイント」などの見出し（全角・文字間の空白も可） | 手順・急所として読み取り |
| 番号の無い行に続く文（1 つの手順が 2 行に分かれている） | 前の手順につなげる |
| 手順の行に置いた ✚（十字形）・◆（ひし形）の図形 | 手順の「✚ 安全」「◆ 品質」の印（ヘッダーの凡例「安全ポイント」「品質ポイント」から自動で判断） |
| 管理番号・工程名・作業名称（部品名） などの項目名 | 要領書の画面でも同じ名前で表示 |
| 管理番号・工程名などの全角英数字（例：Ｎライン） | 半角にそろえる（Nライン）。一覧の絞り込みで同じラインが 2 つに分かれないように |
| 図解Ｎｏ．（①②…） | 写真を取り込まないため、取り込まない |
| 写真・図解の欄 | 取り込まない（手順の行に貼られた写真だけ取り込む） |
| 改訂履歴の欄（左右 2 列の表にも対応） | 日付・内容が書かれた行だけ取り込む |

見出しの名前は、エディタの「見出しの名前」欄や、設定画面の「要領書の見出しの名前」（新しく作る要領書の初期値）でも変えられます。
「GK-」のように番号が入っていない管理番号のときは、ファイル名は日時から自動で付けます（他の要領書を上書きしません）。
- `samples/excel-sample.xlsx` が取り込める形の例です（2 種類のレイアウト）

### 2. 「フォルダに保存」が使えない場合（手作業で配置）

「フォルダに保存」ボタンが出ないブラウザでは「ファイルに書き出す」でダウンロードし、次のように配置します。

1. ダウンロードした `.js` ファイル → `manuals` フォルダへ
2. 使った動画 → `videos` フォルダへ、写真 → `images` フォルダへ
3. 新しい要領書なら `manuals/catalog.js` の `files` にファイル名を追加

```js
  files: [
    "sample-001.js",
    "WI-A-002.js"                   // ← 追加
  ]
```

### 工場・課・工程の名前（画面の上に出る名前）

メニューの「**✎ 名前を変える**」（または「設定」→「工場・課・工程の名前」）で変えられます。
1 段目に工場、2 段目に課、3 段目に工程…のように入れると、画面の上に「本社工場 ＞ 製造二課 ＞ 組立工程」と表示されます。段は増やしたり（○○係など）、使わない段は空欄にしたりできます。

### カテゴリー（一覧の絞り込み）

一覧の絞り込みは、各要領書の「**ライン**」「**製品（品番・品名）**」「**工程**」の欄から自動で作られます。
社内フォーマットの「工程名」欄にライン名（例：Nライン）を書いている場合は、設定画面の「一覧で絞り込む項目」で「工程」の表示名を「工程名」などに変えると分かりやすくなります。

**カテゴリーの編集は、一覧の「設定」（`settings.html`）から行えます**（Chrome / Edge）。

| できること | 内容 |
|---|---|
| 名前の変更 | 「Aライン」→「第1ライン」など。**その名前を使っている要領書もまとめて書き換わります** |
| まとめる | 2 つを同じ名前にすると 1 つにまとまります（表記ゆれの修正） |
| 追加 | 新しいラインや製品を先に登録しておけます（エディタの入力候補に出ます） |
| 削除 | 使っている要領書のその欄は空（未設定）になります |
| 並べ替え | 一覧での表示順になります |
| 項目の表示名・順番 | 「ライン」→「職場」、「工程」→「業務」など。どの項目で絞り込むか・順番も選べます |
| 工場名 | 一覧の上部に表示する名前 |

- エディタでは、すでに登録されている名前が候補として出ます。候補から選ぶと表記がそろい、同じラインが 2 つに分かれる（「Aライン」と「A ライン」など）のを防げます
- 複数のラインで使う要領書は「Aライン、Bライン」のように「、」で区切ると、どちらで絞り込んでも表示されます

既存の要領書を直すときは、表示画面の「編集」から開いて保存し、同じ名前で上書きしてください。

### 動画について

**スマホで撮る場合は、撮影前に一度だけ `guide.html`（撮影ガイド）の設定をしてください。** iPhone・Android の設定方法を載せています（一覧・エディタの「撮影ガイド」ボタンから開けます。印刷して現場に貼ることもできます）。
iPhone の初期設定（HEVC・4K・HDR）のままだと、他の PC で再生できない・カクつく・色が白っぽくなることがあります。

エディタで動画を選ぶと、**自動でチェック**して結果を動画欄の下に表示します。

| 表示 | 内容 |
|---|---|
| ✓ 問題ありません | そのまま使えます |
| ⚠ 注意 | HEVC（他の PC で再生できない可能性）、4K など高画質すぎる、HDR、容量が大きい |
| ✕ 使えません | この PC で再生できない。写真の場合は HEIC 形式（表示できない） |

iPhone の動画（.MOV）もそのまま選べます。

**PC 作業**は画面録画で撮ります（Windows 11 の Snipping Tool：Win＋Shift＋R など。詳しくは撮影ガイド）。
静止画の方が分かりやすい手順は、Win＋Shift＋S で画面をコピーして、エディタの手順の欄で **Ctrl＋V** で写真として貼り付けられます。
写真の下の「**✎ 書き込み**」で、□ 囲み・→ 矢印・① 番号・文字（赤／青）を書き込めます（「① の［保存］をクリック」のような説明に）。書き込みは後から直せます。要領書の画面では、写真をタップすると拡大表示されます。
動画・写真のファイルは、手順の欄に**ドラッグ＆ドロップ**しても入れられます。

- 形式は **MP4（H.264）** をおすすめします（Windows の Chrome / Edge で確実に再生できます）
- 低スペック PC で使う場合は **720p（1280×720）以下・30fps 以下** にすると軽くなります
- スマホで撮った動画は、そのままだと容量が大きい場合があります。動画編集ソフトなどで 720p に変換すると快適です
- サンプルの `videos/sample.mp4` は動作確認用のダミー動画です

### 区分の目印

急所には種類を付けられます：<b>安全</b>（赤）・<b>品質</b>（青）・<b>やりやすさ</b>（紺）。
紺と白を基本にして、注意が必要な所だけ色が付くようにしています。

## データ形式（参考）

要領書ファイルは次の形式です。エディタを使わず直接書き換えることもできます。

```js
registerManual({
  "id": "WI-A-001",
  "docNo": "WI-A-001",
  "title": "作業名",
  "category": "組立", "process": "工程", "line": "ライン", "product": "品番",
  "revision": "1", "issued": "2026-04-01", "updated": "2026-04-01",
  "author": "作成者", "checker": "確認者", "inspector": "点検者", "approver": "承認者",
  "stamps": { "approver": "images/WI-A-001_stamp_approver.png" },
  "purpose": "目的",
  "cautions": ["安全上の注意"],
  "ppe": ["保護具"],
  "tools": [{ "name": "治工具", "qty": "1本" }],
  "materials": [{ "name": "部品", "qty": "4本" }],
  "steps": [
    {
      "title": "主なステップ",
      "detail": "詳しい説明",
      "time": 10,
      "image": "images/step1.jpg",
      "video": { "src": "videos/xxx.mp4", "start": "0:00", "end": "0:06" },
      "points": [
        { "text": "急所", "reason": "理由", "kind": "safety",
          "video": { "src": "videos/xxx.mp4", "start": "0:03", "end": "0:05" } }
      ]
    }
  ],
  "revisions": [{ "rev": "1", "date": "2026-04-01", "content": "新規制定", "by": "作成者" }]
});
```

- `kind`：`safety`（安全）／`quality`（品質）／`ease`（やりやすさ）／空欄
- `start` / `end`：`"1:23"` または秒数。`end` が空欄なら最後まで再生

## スティック PC など力の弱い PC で使うとき

- 写真は、入れたときに自動で小さくします（長い辺 1600px、画面のコピーは 1920px）。すでにある大きな写真は、設定画面の「**images フォルダの写真を軽くする**」でまとめて小さくできます（元の写真は `images/_original` に残ります）
- 動画がカクつくときは「720p・30fps・H.264」で撮ると軽くなります
- 自動翻訳（Chrome の端末内翻訳）は PC の力を使うので、翻訳はリーダーの PC で行い、作業者の PC では見るだけにするのがおすすめです
- 試しに CPU を 6 倍遅くした状態で、200 件の要領書でも、かんたん画面が約 1.4 秒、要領書が約 1.2 秒で開くことを確かめています

## オフラインで使うときのポイント

- フォルダ一式（`index.html`・`manual.html`・`editor.html`・`assets`・`manuals`・`videos`・`images`）をまとめてコピーすれば、別の PC・別の工場でもそのまま動きます
- 動画も同じフォルダ内に置くので、ネットワークが無い現場でも再生できます
- 文字サイズ・再生速度・繰り返しの設定、編集途中の内容は、その PC のブラウザ内に保存されます（外部には送信されません）

## 「フォルダに保存」ができないとき

| 状況 | 対処 |
|---|---|
| フォルダを選ぶ画面でどれを選べばよいか分からない | 選ぶ前に「保存先のフォルダを選びます」という案内が出て、選ぶフォルダ（例：デスクトップ ＞ sagyo-youryousho-2 ＞ sagyo-youryousho）が表示されます。そのフォルダを開いて「フォルダーの選択」を押してください |
| 「フォルダに保存」ボタンが無い | Chrome か Edge で開いてください（他のブラウザでは「ファイルに書き出す」を使います） |
| 保存したのに一覧に出ない | エディタの下にある「保存先：○○」を確認し、違えば「変更」を押して、いま開いている index.html があるフォルダを選び直してください |
| 「manuals フォルダが見つかりません」と出る | index.html があるフォルダを選んでください。ZIP を展開して同じ名前のフォルダが二重になっている場合は、外側を選んでも自動で中のフォルダを使います |
| 「書き込みが許可されませんでした」と出る | もう一度保存し、ブラウザの確認で「ファイルを編集」（許可）を選んでください |
| どうしてもできない | 「ファイルに書き出す」でダウンロードし、manuals フォルダに入れてください（下の「手作業で配置」） |

新しい版のテンプレートを別の場所に展開した場合も、前のフォルダに間違えて保存しないよう、保存のときに確認します。
