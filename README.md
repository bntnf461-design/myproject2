# 備品・副資材管理アプリ（バーコード / QR）

© 2026 All rights reserved. 無断で複製・改変・転用・再配布することを禁じます（詳しくは「著作権について.txt」）。

棚から備品・副資材を取る時の「正の字」記録を、バーコード／QRコードの読み取りに置き換えるWebアプリです。
補充（入庫）も同じ画面で記録でき、在庫数・使用ペース・要補充品目をダッシュボードで見える化します。

## できること

| 画面 | 内容 |
|---|---|
| **スキャン** | 品目ラベルを読むだけで記録(数量を選ばなければ、ラベルの「1回 ○個」の数)。入力・ボタン操作は不要。数量指定・直前の取消・担当者名(任意)にも対応。読み取り成功/失敗を音と色で表示 |
| **補充お知らせ** | 出庫で在庫が発注点を下回った瞬間に、画面全体が黄色(在庫切れは赤)に点滅し、チャイムと音声で「○○が、発注点を下回りました。残りは○個です。補充をお願いします。」と知らせる |
| **ダッシュボード** | 要補充/在庫切れ件数、全品目の在庫タイル(色分け・発注点ライン)、日別の出庫回数グラフ、よく使う品目ランキング、在庫の残り日数。自動更新し、新たに要補充になった品目を点滅バナー・音声で知らせる |
| **補充リスト** | 発注点を下回った品目と発注目安数を一覧化。「発注済」を付けて二重発注を防止(補充して在庫が発注点を上回ると自動解除。一部だけ届いた時は残る)。印刷可 |
| **品目のフォルダ（分類）** | 品目一覧の左に、Windows のエクスプローラーのようなフォルダを表示。右クリック（または「＋ 新しいフォルダ」）でフォルダの作成・名前の変更・削除、フォルダの中のフォルダも作れる。品目やフォルダをドラッグして移せる。フォルダを削除しても品目は消さず、1つ上のフォルダへ移す。Excel のひな形の「フォルダ」シートに大分類・中分類・小分類を書いて取り込むと、フォルダをまとめて作れる（空のフォルダも。「品目」シートの「分類」はそのフォルダから選べる）。「分類」に `清掃/ゴミ袋` のように / で区切って書いてもよい |
| **金額（税込）** | 品目に「単価（税込）」を登録すると、品目一覧に在庫金額（在庫 × 単価）と、フォルダ・全体の合計を表示。棚卸しの一覧・結果・CSV にも金額とズレの金額を出す（単価は数えた時点のものを残す） |
| **品目** | 品目の登録・編集・削除、棚卸(実在庫に合わせる)、**Excel(品目登録シート)・CSVの取込/出力**。Excel はひな形をダウンロードして入れ、そのまま取り込める(CSV に保存し直す必要なし。Shift_JIS の CSV も可) |
| **履歴** | 入出庫・棚卸の全記録。品目/区分/期間/担当者で絞り込み、CSV出力 |
| **ラベル印刷** | 棚に貼る QR + バーコード(Code128) ラベルを A4 に印刷。モード切替・数量指定用の「操作用コード」も印刷可 |
| **棚卸し** | 一覧に今の在庫と並べて数えた数を入れる(ラベルを読んで数える方法も可)だけで在庫を実物に合わせる。表示される在庫は参考で、必ず実物を数えて入れる。終わると「記録とのズレ一覧」と「読み忘れが多い品目」を表示、CSV出力可。**棚卸しの期間**（例: 10月28日〜11月28日）を決めておくと、期間の外では「期間外です」と警告する（期間外でも数えられる）。フォルダで絞り込んで数えられる |
| **月次レポート** | 月ごとの出庫・補充回数、よく使った品目、6か月の推移を画面に表示。品目別・日別・月別推移(12か月)・担当者別・棚卸・履歴のシートとグラフ入りの Excel をダウンロード |
| **担当者カード** | 担当者ごとのカード(QR+バーコード)を印刷。スキャン画面で1回読むと担当者が切り替わる。共用端末向けに「○分操作がなければ外す」設定あり |
| **入力ミスの確認** | いつもより大幅に多い数(初期設定: いつもの5倍より多く、かつ10より多い。補充は「発注数」もいつもの数に含める)で記録しようとした時だけ「本当に50個？」と確認。同じラベルをもう一度読むと「はい」 |
| **自動バックアップ** | 起動中、1日1回 stock.db を自動でコピー(初期設定: アプリのフォルダの backup、30日分)。保存先は共有フォルダなどに変更可。失敗するとダッシュボードに表示 |
| **読み方の登録** | 音声が品名を読み間違える品目に、正しい読み方(ひらがな・カタカナ)を登録できる |
| **自動起動** | `自動起動_オン.bat` を1回実行すると、サーバPCにサインインした時にアプリが自動で起動する(`自動起動_オフ.bat` で解除)。二重起動は防止 |
| **ヘルプ（質問する）** | 画面右上の「？ ヘルプ」で、知りたいことをふつうの言葉で入れると（例: 事務所で受け取った品物の記録は？）、よくある質問から近い答えと「この画面を開く」ボタンを出す。日本語/インドネシア語。中身は `help_data.py` |
| **ライセンス（使えるPCの固定）** | 初回起動時に「ライセンス」画面でマシンコードを表示。発行者が署名したライセンスキー（license.key）を登録したサーバPCでだけ動く。期限付きのキーにも対応し、期限30日前からダッシュボードで知らせる |

## 起動方法

現場のPC 1台をサーバにし、タブレット・スマホ・PCのブラウザからアクセスします。

**Windows の場合**

1. 本アプリのフォルダにある `start.bat` をダブルクリックします。
   必要な部品は全部入っているので、ダウンロードなどは要らず、すぐ起動します（Windows 10 / 11 の 64ビット）。
2. 自動でブラウザが開きます。黒い画面は閉じずにそのままにしてください（閉じるとアプリが止まります）。

データは同じフォルダの `stock.db` に保存されます（毎日自動でバックアップされます）。
バックアップの保存先は「設定」→「自動バックアップ」の「📁 フォルダを選ぶ」で、USBメモリや共有ドライブから選べます。
保存先は環境変数 `STOCK_DB` で変更できます。

## 画面をインドネシア語にする

画面の右上の **「🌐 Bahasa Indonesia」** を押すと、その端末の画面がインドネシア語になります（「🌐 日本語」で戻ります）。
端末ごとに覚えるので、作業者用のタブレットだけインドネシア語、事務所のPCは日本語、という使い方ができます。

- 品目の登録画面の **「品名（インドネシア語）」** に入れておくと、インドネシア語の画面ではその名前が出ます（空欄なら日本語の品名）。
- 音声のお知らせもインドネシア語で話します。Edge なら「Gadis」などの自然な声が使えます（ネット接続が必要）。インドネシア語の声が無い端末では、音と画面の色だけで知らせます。
- 作業者用の A4 手順書は「ラベル印刷」→「作業者用 手順書（インドネシア語）」で印刷できます。
- 月次レポート（Excel）とCSVの見出しは日本語のままです。

## 複数の現場をまとめて見る（現場名）

- 「設定」→「現場名・ほかの現場」で **この現場の名前** を入れると、画面の上・タブ・月次レポートに出ます。
- 同じ画面の **「拠点コード」** に拠点（課・現場）ごとにちがう文字（例: A課は `A`、B課は `B`）を入れると、新しく登録する品目のコードがその文字で始まり（`A0001`・`B0001`）、拠点の間でコードが被りません。ほかの拠点のラベルを読むと「ほかの拠点のラベルのようです」と出ます。決める前に登録した品目（`SZ0001` など）は「今の品目のコードを…付きに変える」で付け替えられます（記録はそのまま。ラベルは印刷し直し）。全現場の画面では、拠点コードが同じ現場があると知らせます。
- **「🔍 ほかの現場を探す」** を押すと、社内のネットワークにあるほかの現場が見つかります。チェックして登録すると、メニューに **「全現場」** が出て、全部の現場の在庫・補充が必要な品目を1つの画面で見られます（各現場のPCから直接読み込み、1分ごとに更新）。見つからない現場は、アドレスを直接入力します。
- 事務所のPCにはアプリを入れず、ブラウザで開くだけです。事務所から各現場のPCへ社内ネットワークでつながる必要があります。
- **どの現場からでも見られます。** 各現場は、どこか1つの現場のアドレスだけ登録すれば、その現場に登録されている現場も自動で出ます。
- 登録して保存した時に、その現場に **つながるかをすぐ確かめます**（つながらない現場は知らせます）。
- 現場のPCの **アドレスが変わっても**、全現場の画面が社内のネットワークから自動で探し直して、新しいアドレスに登録し直します（同じネットワークの範囲にある現場のみ）。
- つながらない現場は、**前回つながった時の在庫** を薄く表示し、「つながらない時は」に確かめる順番を出します。
- 各現場のカードの **「開く」「入庫」「補充リスト」** から、その現場の画面をすぐ開けます（事務所で受け取った品物の入庫もここから）。
- 現場ごとにアプリの版が違う時は、カードに「アプリの版が違います」と出ます。

### アドレスの調べ方・事務所での使い方

- アドレスは、その現場のPCの「設定」→「ほかのPCからつなぐ」、アプリの黒い画面、または Windows のコマンドプロンプトで `ipconfig`（IPv4 アドレス）で分かります。
- 事務所ではアプリを入れず、ブラウザで `http://（現場のアドレス）:5000/sites` を開きます（お気に入りに入れておくと便利）。1分ごとに自動で更新します。
- 事務所で補充を受けた時は、上のメニューの **「入庫」** を開き、品名で探して届いた数を入れ **Enter** を押すだけで記録できます（スマホは「入庫」ボタン）。間違えた時は、その行の「取り消し」で戻せます。「補充リスト」の右の欄からも記録できます。
- くわしくは管理者用説明書の 2-11・2-12。

## 発注担当者に知らせる（品目ごと）

- 「設定」→「発注担当者・通知」で担当者（名前・メールアドレス）を登録し、品目ごとに担当者を選びます（品目一覧でまとめて決められます）。
- 発注点を下回った時・在庫切れになった時に、その品目の担当者にメールで知らせます（メールの送信設定を一度だけ入れる。テスト送信あり）。
- **Teams のチャンネルにも知らせられます**（メールの設定は不要）。Teams のチャンネルの「…」→「ワークフロー」→「Webhook 要求を受信するとチャネルに投稿する」で URL を作り、「発注担当者・通知」の「Teams に知らせる」に貼り付けます。品名・今の在庫・発注の目安・発注担当者が載ったカードが出ます（担当者が決まっていない品目も知らせる）。サーバPCがインターネットにつながっている必要があります。
- 補充リストは担当者で絞り込めます。自分の名前を選んでおくと、担当の品目が下回った時に画面が音と音声で知らせます。

## インターネットを使う機能

アプリを使うには、サーバPCと、読み取りをする端末が、同じ社内のネットワーク（LAN・Wi-Fi）につながっている必要があります。
インターネットを使うのは、次の機能だけです。

- **Teams・メールでの通知**: サーバPCがインターネットにつながっている時だけ送れます。つながらない現場は、画面と音のお知らせだけになります。
- **自然な声**: Edge の「Natural」の声はネットを使うため、ネットがない時は自動でPCに入っている声（Haruka など）に切り替わります。
- **画面の文字の形**: ネットがない時はPCに入っている文字（メイリオなど）で表示されます。使い方は変わりません。

そのほか:

- ライセンスキーの確認はPCの中だけで行うので、ネット接続は要りません（キーはUSBメモリなどで渡します）。
- ほかのPC・タブレットとは、社内のネットワーク（LAN・Wi-Fi）だけでつながります。
- ネットにつながらないPCは時計がずれやすくなる（時刻合わせがネット経由のため）ので、月に一度は時計を確かめてください。記録の時刻・月次レポート・ライセンスの期限に使います。

## ほかのPC・タブレットからつなぐ

アプリを動かすのは**サーバPC 1台だけ**です。ほかのPC・タブレット・スマホは、ブラウザで
`http://(サーバPCのアドレス):5000/` を開くだけで使えます（アプリを入れる必要はありません。台数の制限もありません）。

- アドレスは、サーバPCの「設定」→「ほかのPCからつなぐ」に、QRコードと一緒に出ています（起動時の黒い画面にも出ます）。
- サーバPCのアドレスが変わることがある時は、PCの名前のアドレス（例: `http://DESKTOP-AB12:5000/`）を使うと安心です。
- 2台目のPCでもアプリを起動すると、在庫データが別々になるので注意してください。ライセンスキーもサーバPCの分だけで足ります。
- つながらない時は、同じ社内ネットワークか、サーバPCの Windows ファイアウォールで 5000番・5443番が許可されているかを確かめます。

## 導入の流れ

1. **品目を登録** — 「品目」画面で1件ずつ、または **Excel のひな形（品目登録シート）** で一括登録。
   「品目」画面の「Excelのひな形（品目登録シート）」をダウンロード →「品目」シートに1行1品目で入れる →「取り込む（Excel・CSV）」。
   ひな形には「記入例」「説明」シートと、数の入力チェック（0以上の整数など）が付いています。同じものが `docs/品目登録シート（Excelのひな形）.xlsx` にもあります。
   今の品目を直す時は「Excel出力」で出したファイルを直して取り込みます。取り込めなかった行は「○行目: …」と理由が出ます。
   CSV の見出し: `コード,品名,読み方,品名（インドネシア語）,規格,分類,棚番,単位,在庫数,発注点,発注数,1回にとる数,1回にいれる数,仕入先,備考`（品名以外は省略可）
   棚番は空欄でもかまいません。棚番を決めていない時は「設定」→「棚番」で **「棚番を使わない」** にすると、画面・ラベル・通知から棚番が消えます（入れた棚番は残るので、あとで戻せます）。
   (既にある品目は、Excel・CSVに書いた列だけ更新されます。例: `コード,1回にとる数` だけの表も可)
   (コードを空欄にすると `SZ0001` 形式で自動採番（拠点コードを決めていれば `A0001` 形式）。既存の JAN コードなどをそのまま使うこともできます)
2. **発注点・発注数を設定** — 在庫が発注点以下になると「要補充」になり、補充リストに載ります。
3. **ラベルを印刷して棚に貼る** — 「ラベル印刷」から A4 で印刷し、棚の取り出し口に貼ります。
4. **スキャン端末を棚の近くに置く** — スキャン画面を開いたタブレット/PC + スキャナを設置し、
   近くに「操作用コード」を貼っておくと、画面を触らずにモード切替・数量指定ができます。
5. **補充時** — 入庫モードで品目を読み、数量(例: 数量10 のコード)を指定して記録。
6. **月1回などで棚卸** — 「棚卸し」から始めます。ラベルをスキャンして数える方法と、**一覧に今の在庫と並べて数を手入力する方法**（品目が多い時に早い）があります。

## 作業者の手間を増やさない工夫

- **読むだけで記録**: 品目ラベルを読めば、ラベルの「1回 ○個」の数で即記録。確定ボタンや品目選択は不要です。
- **2個以上取る時だけ**数量を変更。画面の**数量ボタンを押すと大きなテンキー**が開き、数字を押して「決定」。よく使う数はワンタッチ(最初は とる: 1/2/3/5/10/20、いれる: 1/5/10/20/30/50)。**ワンタッチの数字は「設定」画面で、とる・いれる別に自由に変えられます**(最大6個)。「数量5」等の操作用コードを読んでも変えられます。記録後は自動で「ラベルの数」に戻ります。
  テンキーを開いたままラベルを読んでも、入力中の数量で記録されます。
- **品目ごとの「1回の数」**: 品目の編集画面で「1回にとる数」「1回にいれる数」を決めておくと、数量を指定せずに読んだ時はその数で記録されます(例: 手袋は1回2箱、補充は1ケース12個)。スキャン画面の数量ボタンは普段「ラベルの数」と表示され、棚ラベルに印字された「1回 ○個」の数で記録されます(補充の数が1以外なら「（補充 12）」も印字)。数字を選んだ時だけその数が優先されます。
- **入庫モードの戻し忘れ防止**: 入庫のあと30秒操作がなければ自動で出庫モードに戻ります。
- **読み取り欄を気にしなくてよい**: どこにフォーカスがあってもスキャナの入力を受け付けます。
- **間違えたら「直前を取消」**(または「取消」コードを読む)。
- **専用端末表示**: `http://<IP>:5000/scan?kiosk=1` を開くとメニューが隠れ、スキャン画面だけになります。
- 担当者名は任意です(端末ごとに一度入れておけば保存されます)。

## 補充タイミングのお知らせ

| タイミング | スキャン画面 | ダッシュボード |
|---|---|---|
| 発注点を下回った瞬間 | 画面全体が**黄色で点滅** + ピンポーン + 音声「○○が、発注点を下回りました。残りは○個です。補充をお願いします。」 | 上部に**黄色の点滅バナー** + 音声、該当タイルが点滅 |
| 在庫切れになった瞬間 | 画面全体が**赤で点滅** + 警報音 + 音声「○○が、在庫切れになりました。補充をお願いします。」 | **赤の点滅バナー** + 音声 |
| 要補充の品目をさらに取った時 | 結果欄が黄色 + 短い警告音 + 音声「残りは○個です。補充をお願いします。」 | — |
| 常時 | 画面上部の赤い帯に「補充が必要なもの ○件」 | 要補充件数・タイルの色分け |

- ダッシュボードのお知らせは「タッチで確認済み」にするまで、10分ごとに音声で繰り返します。補充して在庫が発注点を上回ると自動で消えます。
- ブラウザの制約で、**音を出すには画面を一度タッチ**する必要があります。掲示用モニターでは起動後に「🔊 補充お知らせの音声をオンにする」を押してください。
- 音声読み上げは端末の日本語音声を使い、その中で最も自然な声を自動で選びます。**Microsoft Edge で開くと「Nanami (Natural)」などの自然な声**が使えておすすめです(インターネット接続が必要)。
- スキャン画面の「設定」で、読み上げのオン/オフ・声の種類・速さを変更し、「声を試しに聞く」で確認できます。
- **棚のそばに画面がない現場向け**に、スキャン画面の「設定（この端末）」で次を選べます（どちらも最初はオフ）。
  - 「記録できなかった時も、声で知らせる」: サーバにつながらない時・記録や取り消しができなかった時・未登録のラベルを読んだ時に、声で知らせる。
  - 「モード・数量の切り替えと取り消しも読み上げる」: 「いれるモードです」「数量、5」「○○の記録を、取り消しました」のように読み上げる。
  タブレットの音を棚のそばの Bluetooth スピーカーから出し、「出庫・入庫のたびに品名を読み上げる」と一緒に使うと、画面を見なくても記録できたかが分かります。

## 読み取り機器について

- **USB / Bluetooth バーコードスキャナ(推奨)**: キーボードとして入力されるタイプならそのまま使えます。
  QRも読むなら「2次元(2D)対応」の機種を、1次元専用の機種ならバーコード(Code128)を読ませてください。
  読み取り後に Enter(改行) が送られる設定にしてください(多くの機種で初期設定)。
- **スマホ / タブレットのカメラ**: スマホのブラウザで `https://(サーバPCのアドレス):5443/scan` を開き、カメラボタンを押します。
  - アプリは起動時に、パソコン用(`http://…:5000`)とスマホのカメラ用(`https://…:5443`)の2つのアドレスで同時に待ち受けます(ブラウザの決まりで、カメラは https でしか使えないため)。
  - 初回は「安全ではありません」と出るので「詳細」→「アクセスする」を押します(社内専用の証明書のため)。証明書はアプリのフォルダの `ssl` に保存され、次からも同じものを使います。
  - 読み取りライブラリはアプリに同梱しているので、ダウンロードは要りません(iPhone・Android とも)。
  - カメラを同じラベルに向け続けても記録は1回だけです。同じ品目をもう一度記録する時は、一度カメラをラベルから外します。
  - ファイアウォールで聞かれたら「許可」してください(5000番と5443番を使います)。
- **作業者用 手順書(A4 1枚)**: 「ラベル印刷」→「作業者用 手順書(A4)」から印刷できます。とり方・いれ方・画面の色と音・スキャナ(USB・Bluetooth)の使い方を1枚にまとめています。

## 数量入りのラベル（同じ品目に「1回 1枚」「1回 5枚」など）

「ラベル印刷」の **「1回の数を入れたラベル」** に `1, 5` のように入れると、品目ごとに「1回 1」「1回 5」のラベルを作ります。
コードは `SZ0001.Q5` のように品目コードの後ろに数が付き、読むとその数で記録されます（数量ボタンで数を選んでいる時は、そちらが優先）。
棚卸しでは数の部分は無視され、同じ品目として数えます。

## 操作用コード

| コード | 動作 |
|---|---|
| `CMD-OUT` | 出庫モードにする |
| `CMD-IN` | 入庫(補充)モードにする |
| `CMD-UNDO` | 直前の記録を取り消す |
| `CMD-Q数字`（例: `CMD-Q5`） | 次に読む品目の数量を指定(記録後は「ラベルの数」に戻る)。「設定」画面で決めた数字のカードが印刷されます |
| `CMD-U数字`（例: `CMD-U3`） | 担当者カード。読むとその人を担当者にする(「設定」→「担当者カード」で登録・印刷) |

## 注意

- ログイン機能はありません。社内LAN内での利用を想定しています。
- バックアップから元に戻す時は、アプリを止めてからバックアップのファイル(`stock_年月日_時分.db`)をアプリのフォルダにコピーし、`stock.db` に名前を変えて起動します。
- 在庫数はマイナスになりません。記録上の在庫より多く取った時は、取った数は記録したうえで在庫を0にし、「記録上の在庫より多く取りました」と画面に出します（履歴にも残ります）。読み忘れの合図なので、棚卸しで数を確かめてください。「とりけし」をすると、もとの在庫に戻ります。
- 残日数は直近30日の平均使用量から計算しています。
