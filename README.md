# Nライン切面孔明け作業日報（デジタル版）

Excel 日報「品質記録：№5-(7)-10（2020.10 版）」を HTML 化した入力フォームです。
`index.html` をブラウザで開くだけで使えます（サーバー不要）。

## 機能
- Excel と同じレイアウトで全項目を手入力（明細 19 行、不良内訳、打刻マーク確認、使用素板、投入時間、稼働状況、コアドリル径、トピックス など）
- 自動計算（薄い青のセル）：良品歩留、工程不良・素板不良の内訳合計、合計行、投入時間合計
- 稼働状況は 30 分単位で A/P/T/W/E/O を選択、時間を自動集計
- 入力は作業日ごとにブラウザ（localStorage）へ自動保存。作業日を変えるとその日の日報を表示
- JSON 書出し/読込み、明細の CSV 書出し、A3 横での印刷
- 明細表では Enter で下のセルへ移動（Shift+Enter で上へ）
- 「マーク交換前の打刻シール」は写真添付で代替可能
