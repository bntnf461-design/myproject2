# ライン進捗アンドン（ver 1.0.0）

テンキーで各ラインの実績（Act）をカウントし、差異・進捗率・状況・終了時間を自動で更新するアンドン画面です。
`index.html` をブラウザ（Chrome / Edge）で開くだけで動きます。インストールやインターネット接続は不要です。
事務所の PC からも見たり変更したりする場合は、下の「事務所との共有」の手順で現場PCをサーバー役にします。

詳しい使い方は、画面右上の **「？ 使い方」**（説明書）で確認できます。説明書は「🖨 印刷」で紙に印刷できます。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| `index.html` | アンドン本体（画面） |
| `andon-server.ps1` | 事務所と共有するためのサーバー（Windows 標準の PowerShell で動作） |
| `start-server.bat` | サーバーを起動して画面を開く（ダブルクリック） |
| `setup-firewall.bat` | 事務所からつなげるようにする設定（最初に1回・管理者として実行） |
| `register-startup.bat` | Windows のサインイン時にサーバーを自動起動する |
| `計画取込テンプレート.xlsx` | Excel 取り込み用の雛形 |
| `アンドン（事務所PC用）.url` など | サーバー起動時に自動でできる、事務所PC に配るショートカット |

## 事務所との共有（社内LAN）

現場PCを「サーバー役」にすると、事務所などの PC のブラウザから同じ画面を開いて、見たり変更したりできます。
計画・部品・設定の変更、実績の修正、作業開始など、現場と同じ操作ができ、変更は約2秒で全部の画面に反映されます。
追加のソフトやインターネット接続は不要です。

1. **現場PC**：このフォルダー一式を現場PCに置きます。
2. `setup-firewall.bat` を右クリック →「管理者として実行」（最初に1回）。
   実行できない場合は、システム担当者に「TCP 8080 番の受信許可（ドメイン／プライベート）」を依頼してください。
3. `start-server.bat` をダブルクリック。黒い画面（サーバー）が開き、ブラウザで `http://localhost:8080/` が開きます。**黒い画面は閉じないでください**（最小化は可）。
4. 毎朝自動で起動するには `register-startup.bat` をダブルクリック。
5. **事務所PC**：アドレスを打たずに開けます。
   - 現場PCのアンドンのフォルダーにできる **「アンドン（事務所PC用）」「本日の計画（事務所PC用）」** のショートカットを、共有フォルダー・メール・USB で事務所PCのデスクトップにコピー → ダブルクリックで開きます。
   - 一度開いた PC では「⚙ 設定 → 事務所との共有 → 💾 デスクトップ用」で保存したファイルをデスクトップに置けば、次からダブルクリックで開けます。
   - 「📋 アドレスをコピー」でアドレス（`http://現場PCの名前:8080/`）をメールやチャットで送れます。

- **これまでのデータを引き継ぐ**：前に `index.html` を直接開いて使っていた場合は、その画面で「⚙ 設定 → 💾 データを書き出す」→ サーバーの画面で「📂 データを読み込む」。
- 画面上部の **● 共有中** がつながっている印です。**● サーバー未接続** でもその PC で操作でき、つながった時に自動で合わせます。
- 現場と事務所で同時に変更しても、両方の変更が残るように自動で合わせます（同じラインを両方で数えた場合は両方の数を足します）。
- データは現場PCの `andon-data.json` に保存され、`backup` フォルダーに1日1回コピーが残ります（60日分）。
- 現場PCがスリープすると事務所から見られなくなります。電源設定で「スリープしない」にしてください。
- サーバーを使わずに `index.html` を直接開くと、これまでどおりその PC だけで動きます。

## 本日の計画（📋 本日）

「📋 本日」ボタン（またはテンキー ＋）で、今日の計画を1画面で確認できます。

- **タイムライン**：ラインごとに部品の順番・開始〜終了時刻を帯で表示（休憩は斜線、現在時刻は赤線）。
  稼働中は完了＝灰色、作業中＝青枠（進み具合つき）で表示し、遅れた分は後ろの部品もずれます。帯の下の細線は当初の計画です。
- **一覧表**：部品ごとの数量・1カートンあたりの時間・所要時間・開始／終了・遅れ。
- 「◀ 前の日／次の日 ▶」で他の日の計画も確認でき、「🖨 印刷」で印刷できます。
- 事務所からは `http://現場PCの名前:8080/#plan` を開くと、最初からこの画面になります。

## 準備（最初に1回）

「⚙ 設定」で次の項目を決めます。

- ライン数（1〜8。4 ライン・5 ラインの運用に対応）、ライン名、+1 キー、行の色
- **部品の登録**：部品名・作業人数・1カートンあたりの時間（単位は 秒・分・時間 から選択）。
  作業人数で時間が変わる部品は「＋ 人数を追加」で人数ごとに登録します（例：2人 60秒・3人 45秒）。
  計画では部品ごとに人数を選び、その人数の時間で目標・終了時間を計算します。画面では「部品名（3人）」と表示します。
- **1カートンの個数（MAX）**：部品ごとに決められます（空欄でも可）。決めた部品は計画数量を**個数**で入れ、テンキー1回で1カートン分、
  最後は残りの端数だけ増えます（例：1000個・1カートン300個 → 300・600・900・1000 の4回で完了）。−1 も1カートン分戻ります。
  空欄の部品は今までどおり計画数量をカートン数で入れ、テンキー1回で +1 です。
- 作業開始時刻（「自動で作業開始する」にチェックを入れると、毎日その時刻に自動で開始）
- 休憩時間（複数登録できます）
- 状況（●）の判定：段階の数（最大10）・区切りの %・色（初期値：100%以上＝緑、90%以上＝黄、それ未満＝赤）、操作キー

## 計画の入力（部品と順番）

1日に1ラインで複数の部品を作れます。部品は上から順番に作ります。

- **カレンダーで入力**：「📅 計画」→ 日付をクリック → ラインごとに「＋ 部品を追加」で登録した部品を呼び出し、作業人数とカートン数を入力（小数も可）。▲▼ で順番を入れ替えます。
- **当日に数量だけ直す**：表の計画数量をクリックするか、テンキー ＊ → 数字（. で小数点）→ Enter。今の部品の数量が変わります。
- **Excel から取り込む**：下の「Excel から取り込む」を参照。

## Excel から取り込む

1. 「📅 計画」で取り込みたい月を表示し、**「📄 雛形をダウンロード」** を押します。今のライン名・部品・日付が入った Excel ファイル（`plan_年-月.xlsx`）ができます。
   - リポジトリの `計画取込テンプレート.xlsx` は A〜E ラインの雛形（2026年11月・部品は未登録）です。
2. 「部品」シートに部品名・作業人数・1カートンあたりの時間・単位（秒／分／時間）を入力します（単位が空欄なら秒）。
   人数で時間が変わる部品は、同じ部品名で人数ごとに行を分けます。時間は Excel の時刻の形（例：0:01:30＝1分30秒）でも入力できます。
3. 「計画」シートに1行ずつ入力して保存します。

   | 日付 | ライン | 部品名 | 作業人数 | 計画数量 |
   |---|---|---|---|---|
   | 2026/11/02 | A | 部品X | 3 | 120 |
   |  | A | 部品Y |  | 80.5 |
   | 2026/11/02 | B | 部品X | 2 | 200 |

   - 同じ日・同じラインで複数の部品を作るときは、作る順番に行を並べます（行は挿入して増やせます。日付を省略すると上の行と同じ日）。
   - 部品名は必ず入れます。数量が空欄の行は取り込みません。計画数量は、1カートンの個数を決めた部品は個数、それ以外はカートン数です。
   - 作業人数を空欄にすると、その部品の最初の人数（「部品」シートの最初の行）になります。登録していない人数はエラーになります。
4. **「📥 Excelから取り込み」** でそのファイルを選び、確認画面で「OK」→ カレンダーの「保存」を押します。

- 読み込めるのは **.xlsx** と **.csv**（UTF-8 / Shift_JIS）です。古い .xls は「.xlsx」で保存し直してください。
- ファイルに入っている日の計画は、全ラインともファイルの内容に置き換わります。「部品」シートの部品は追加・更新されます。
- 未登録の部品・数字以外・マイナス・読めない日付がある行は取り込まず、行番号を表示します。
- 前の「品目」シートの雛形も取り込めます（部品名のない、さらに前の形式は取り込めません）。

## テンキー操作（初期設定）

| キー | 動作 |
|---|---|
| 1〜5 | ライン A〜E の実績 +1（1カートンの個数を決めた部品は +1カートン分。今の部品の計画数量まで） |
| . → ラインのキー | 途中変更（作業人数・計画数量）。画面の部品名を押しても開きます |
| − → ラインのキー | そのラインの実績 −1（入力ミスの取消） |
| ラインの −1 キー（設定したとき） | そのラインの実績 −1（1回押すだけ。ラインごとのテンキーに向いています） |
| Enter | 作業開始 → 一時停止 → 再開 |
| ＊ | 計画数量の入力（数字＋Enter で次のラインへ、. で小数点、− で1文字消す） |
| ／ を2回（3秒以内） | リセット |
| ＋ | 本日の計画の表示／アンドン表示に戻る |

- 実績は今の部品の **計画数量までしか増えません**。計画数量が小数（例：10.5）のときは、10 の次に押すと 10.5 になって完了します。
- 部品が計画数量に達すると、次に押した分から **次の部品** を数えます。
- −1 は最後に数えた部品から取り消します（前の部品に戻ることもあります）。
- **途中変更**：「. → ラインのキー」または部品名を押すと、そのラインの作業人数と計画数量を変えられます。
  人数を変えると、変えた時点までの目標は前の人数のまま、それ以降を新しい人数の時間で計算します（終了時間もすぐ変わります）。
  画面の中では テンキー 8・2 で人数を選び、6・4 で次・前の欄、Enter で変更します。
- ラインごとにテンキーを置くときは、「⚙ 設定 → ライン・部品」で各ラインの「−1 キー」を決めておくと、
  「− → ラインのキー」の2回押しが不要になり、別の人の入力と混ざって違うラインを取り消すことがなくなります。
  「−1 キー」のボタンを押してから Delete キーを押すと「なし」に戻せます。

キーの割り当ては設定画面で変更できます。どのラインのキーも同時に受け付けるので、複数ラインで同時に入力できます。
ブラウザではキーボードごとの区別ができないため、テンキーを複数台つなぐ場合は、ラインごとに別のキーを割り当ててください。

## 計算方法

- **現時点目標**（今の部品）= 前の部品が実際に終わった時刻（1番めの部品は作業開始）からの実稼働時間 ÷ その部品の1つあたりの時間（1カートンの個数を決めた部品は 1カートンあたりの時間 ÷ 個数）
  - 小数点以下は切り捨て、計画数量が上限。休憩時間と一時停止中の時間は含めません。
  - 前の部品が遅れると、次の部品の目標・終了時間も自動で後ろへずれます。
- **差異** = 実績 − 現時点目標（不足分は ▲ で表示）
- **進捗率** = 実績 ÷ 現時点目標
- **状況**：🟢 100%以上 / 🟠 90〜100%未満 / 🔴 90%未満（初期値。「⚙ 設定 → 状況の判定」で段階を増やしたり、% と色を変えたりできます。例：110%以上＝青、100%以上＝緑、90%以上＝黄、80%以上＝オレンジ、それ未満＝赤）
- **終了時間** = そのラインの全部品が終わる見込み時刻（休憩を含む）
  - 作業開始前：作業開始時刻 ＋ Σ（計画数量 × 1つあたりの時間）
  - 作業開始後：今の部品の残り × 時間 ＋ 次以降の部品の時間（今の遅れ・進みを含む）。翌日になる場合は「翌」を付けます。
  - 下の小さい「計画」は、遅れがない場合の当初の終了時刻です。

## 実績の履歴・日報（📊 実績）

- 24時に日付が変わるとき、その日の計画・実績・完了時刻・作業開始・最終入力を自動で記録します（1年分）。
- 「📊 実績」で期間を選ぶと、日別の集計とライン・部品ごとの明細を表示します（今日の分は途中の状態）。
- 「📥 Excel に書き出す」で「日別」「明細」の2シート、「🖨 印刷」で日報を印刷できます。
- 実稼働時間は「作業開始〜最後に実績を入力した時刻」（休憩・一時停止を除く）です。

## 管理者の暗証番号（🔒）

- 「⚙ 設定 → 管理」で暗証番号（数字4〜12桁）を決めると、設定の変更に暗証番号が必要になります。
  計画カレンダー・リセット・計画数量の直接入力も、守るかどうかを選べます。
- 実績のカウント・作業開始・本日の計画・実績の表示は、だれでも使えます。
- 一度解除すると、そのパソコンでは決めた時間（初期値10分）ロックが外れます。「🔓 解除中」を押すとすぐロックします。
- 暗証番号は変換した値だけを保存します。忘れたときは、現場PCの `andon-data.json` の `"adminPin"` を `null` に書き換えてサーバーを起動し直します。

## 前日の残りの持ち越し

24時を過ぎたとき、前日に終わらなかった部品の残り（計画 − 実績）があると、翌日の画面に確認が出ます。

- テンキー **Enter で持ち越し**、**− で持ち越さない**。部品ごとのチェックや「本日の計画の前（先に作る）／後」も選べます。
- 残りの数量は「計画 − 実績」で出ますが、実際の端数が違うときは数量の欄を直してから持ち越せます（0 にした部品は持ち越しません）。
- 持ち越した部品には「↻」と元の日付（例：10/30の残り）が付きます。数え始めた部品があるラインでは、その後ろに入ります。
- あとからでも「📋 本日」の「↻ 前日の残りを持ち越す」で持ち越せます。休みの日をはさんでも次の日に持ち越せます。
- 「⚙ 設定 → 前日の残りの持ち越し」で「毎回確認する／自動で持ち越す／持ち越さない」を選べます。
- 共有中は、どの PC で選んでも全部の画面に反映されます（二重に持ち越されることはありません）。

## リセット

- **24時を過ぎると**、実績・作業時間・計画がすべてリセットされ、新しい日の計画がカレンダーから読み込まれます（未入力の日は計画なし）。前日に終わらなかった分は持ち越せます（上記）。
- **リセット** ボタン（またはテンキー ／ ×2）では、実績と作業時間を消去します（計画と設定は残ります）。

データは、共有サーバーを使う場合は現場PCの `andon-data.json`、`index.html` を直接開いた場合はその PC のブラウザに保存されます。どちらも画面を再読み込みしても残ります。前のバージョンのデータは自動で新しい形式に変換されます。
「⚙ 設定 → 💾 データを書き出す／📂 データを読み込む」で、全データのバックアップと復元ができます。
