# ライン進捗アンドン

テンキーで各ラインの実績（Act）をカウントし、差異・進捗率・状況・終了時間を自動で更新するアンドン画面です。
`index.html` をブラウザ（Chrome / Edge）で開くだけで動きます。インストールやサーバーは不要です。

## 使い方

1. 各ラインの **計画数量（Plan）** のセルをクリックして数値を入力します（Enter で次のラインへ移動）。
2. **⚙ 設定** で次の項目を決めます。
   - ライン数（1〜8。4 ライン・5 ラインの運用に対応）
   - ライン名、1個あたりの時間（秒）、+1 キー、行の色
   - 休憩時間（複数登録できます）
   - 状況（●）の色
   - 作業開始時刻（チェックを入れると毎日その時刻に自動で作業開始。前日の実績はリセット）
3. **▶ 作業開始** を押すと計測が始まります。押すたびに「一時停止」と「再開」が切り替わります。
4. 1 個できるごとに、そのラインのキーを押します。

| キー | 動作 |
|---|---|
| テンキー 1〜5 | ライン A〜E の実績 +1（初期設定） |
| テンキー − → ラインのキー | そのラインの実績 −1（入力ミスの取消） |
| テンキー Enter | 作業開始 → 一時停止 → 再開 |
| テンキー ＊ | 計画数量の入力（数字＋Enter で次のラインへ、− で1文字消す） |
| テンキー ／ を2回（3秒以内） | リセット |

キーの割り当ては設定画面で変更できます。どのラインのキーも同時に受け付けるので、複数ラインで同時に入力できます。
ブラウザではキーボードごとの区別ができないため、テンキーを複数台つなぐ場合は、ラインごとに別のキーを割り当ててください。

## 計算方法

- **現時点目標** = 実稼働時間 ÷ 1個あたりの時間（小数点以下は切り捨て、計画数量が上限）
  - 実稼働時間には休憩時間と一時停止中の時間を含めません。
- **差異** = 実績 − 現時点目標（不足分は ▲ で表示）
- **進捗率** = 実績 ÷ 現時点目標
- **状況**：🟢 100%以上 / 🟠 90〜99.9% / 🔴 90%未満
- **終了時間** = 現在時刻 ＋ 残り数 × 1個あたりの時間（間に入る休憩時間も加算）
  - 下の小さい「計画」は、計画どおりのペースで進んだ場合の終了時刻です。

データはブラウザに保存されるため、画面を再読み込みしても実績は残ります。**リセット** を押すと実績・作業時間・終了時間を消去します（計画数量と設定はそのまま残ります）。
