# Nライン切面孔明け作業日報（デジタル版）

日報「品質記録：№5-(7)-10」を HTML 化した入力フォームです。
`index.html` を Edge か Chrome で開くだけで使えます（インストール・ネット接続は不要）。
決まった仕様は `仕様メモ.md` にまとめています。

## はじめに
1. 「設定・データ」→「Excel から読み込み」で `templates/マスタ登録_雛形.xlsx` を読み込み、画面の下の「保存して閉じる」（保存しないで閉じようとすると確かめます）
2. 作業者の名前も設定画面で登録（日報で手打ちした名前は自動で増える）

## 主な機能
- **型式を選ぶと自動入力**：パレット形態・ローカルコード・使用面取りホイール・良品枚数（1PL の残り）
- **切面ロットNo. の自動採番**：`YYMMDD-連番NK`。パレット（1PL）が満タンになるごとに連番 +1
- **前日からの引継ぎ**：前日の切面ロットNo.・良品端数・型式・素板ロット・素板の当残（→前残）
- **素板QR**：どの欄にいても読み取れる（ツールバーの欄でも可）。素板ロットが変わると次の行へ。使用素板（品種・インチ・mm・枚数・PL数）を記録し、当残を計算。型式とローカルコードが違うと警告
- **不良数カウンター取込**（「設定・データ」の「カウンターから取込」。同じパソコンのカウンターは自動）：共有フォルダの JSON（またはバックアップ）から、その日の不良数をいま入力している行へ、作業の開始・終了と段取りを稼働状況へ。何度取り込んでも二重に足さない
- **1台のパソコンでカウンターと日報を使う**：カウンターと日報を同じパソコンの Edge / Chrome で開いておくと、日報の画面で押したテンキー（数字・＋−＊／．・テンキーの Enter）はカウンターへ送られる。日報の数字は、キーボードの上の段の数字で入力する。ツールバーの「テンキー→カウンター」で切り替え（外すと赤く「テンキーは日報に入ります」と出る）。カウンターの画面が開いていないときは、テンキーの数字は日報にも入れずに知らせる。カウンターの状態（作業中・停止中・休憩中・不良数）は日報の上に表示し、今日の日報ではカウンターで数えた不良をその場で今の行へ取り込む
- **日報からカウンターを操作**：日報の型式は、カウンターの製造種類に自動で追加（カウンターが作業していないとき）。作業中のカウンターと違う型式をいまの行で選ぶと、カウンターの作業を終了し、前の型式の作業枚数を作業数として入れ、新しい型式で作業を開始する。カウンターが作業していないときは、上の帯の「カウンターで作業開始」で始める。日報とカウンターの型式が違うときは帯に赤で知らせる。登録されていない型式（打ち間違い）では、カウンターを切り替えず製造種類にも足さない（型式欄が赤くなる）
- **カウンターの休憩**は、稼働状況に E（除外）として入り、稼働時間から除く
- **自動計算**：作業枚数（良品＋不良）、良品歩留、不良の合計、合計行、投入時間合計、使用素板の当残
- 自動で入った値は青い文字。手で書き換えるとそのまま残り、空にすると自動に戻る
- **印刷**：A3 横 1 枚。シールを貼る欄は 55mm × 55mm（6 か所）
- 入力は作業日ごとにブラウザへ自動保存（開いただけでは保存しない）。JSON 書出し/読込み、明細の CSV 書出し
- 起動するといつも今日の日報を開く。作業日は ◀ ▶「今日」ボタンでも変えられる
- 同じ日報を2つのタブで開くと、あとから開いたタブは表示専用になる（「このタブで入力する」で切り替え）
- 1PL を超えた良品枚数・マイナスの当残は赤く表示
- 上の行と同じ型式・切面ロットNo.・素板ロットNo.・パレット形態・ローカルコードは「〃」で表示（画面・印刷とも。値はそのまま残り、欄を選ぶと見えて直せる）
- 画面では文字と行を大きくし、明細の左4列（PL・型式・切面ロット・素板ロット）を固定（横にスクロールしても見える）。いま入力している行は黄色。印刷は A3 の配置のまま
- JSON 書出し/読込み・CSV 書出し・表示中の日報のクリアは「設定・データ」の中
- 明細表では Enter・↓ で下のセルへ移動（Shift+Enter・↑ で上へ）。明細の外では Enter で次の欄へ。作業日で Enter を押すと、いま入力中の行へ。F2 でいつでも、いま入力中の行へ
- 数字の欄は、ホイールや ↑↓ で値が変わらない
- **取り消し**：素板QRの読み取り・行を消す／入れる・読んだ素板の取消は、上のメッセージの「取り消す（元に戻す）」で元に戻せる
- **行を消す・入れる**：明細の欄を選ぶと上に「この行を消す」「この行の上に1行入れる」が出る
- **読んだ素板の一覧**：使用素板の下に、QR で読んだ素板パレットが出る。間違えて読んだものは「取消」で外せる
- メッセージは上に固定（下の方を入力していても見える）。QR が読めたら短い音、確認が要るときは低い音2回
- **印刷の前の確認**：作業者・投入時間・開始と終了・マーク確認・検視台・各行のパレット№ が空なら一覧を出し、押すとその欄へ移る。画面では、これらの欄が空のあいだ黄色の枠で示す
- 画面では、右の3列（パレット№・形態・ローカルコード）も固定。下の段は入力欄を先に、シール欄をあとに小さく出す（印刷の配置は変えない）

## テスト
```bash
NODE_PATH=$(npm root -g) node tests/run.js        # 全部（Playwright と Chromium が必要）
NODE_PATH=$(npm root -g) node tests/run.js h3     # 名前に h3 を含むテストだけ
COUNTER_HTML=…/defect-counter.html NODE_PATH=$(npm root -g) node tests/run.js   # 本物のカウンターとの連携も確かめる
```
見本 10/21 の再現、印刷（A3 横 1 枚・シール欄 55mm）、評価で見つかった不具合（H1〜H4・M1〜M3・M5）、使いやすさの査定で直したところ（U1〜U8）を確かめる。雛形の xlsx は、英数字名の一時ファイルにコピーして読み込む（Playwright が日本語名のファイルを渡せないことがあるため）。

## 注意
- データはこのパソコンのブラウザの中だけにあります。定期的に「JSON書出し」で保存してください
- バーコードリーダーで読むときは、日本語入力をオフにしてください
