# ライン進捗アンドン

テンキーで各ラインの実績（Act）をカウントし、差異・進捗率・状況・終了時間を自動で更新するアンドン画面です。
`index.html` をブラウザ（Chrome / Edge）で開くだけで動きます。インストールやサーバーは不要です。

詳しい使い方は、画面右上の **「？ 使い方」**（説明書）で確認できます。説明書は「🖨 印刷」で紙に印刷できます。

## 準備（最初に1回）

「⚙ 設定」で次の項目を決めます。

- ライン数（1〜8。4 ライン・5 ラインの運用に対応）
- ライン名、1個あたりの時間（秒）、+1 キー、行の色
- 作業開始時刻（「自動で作業開始する」にチェックを入れると、毎日その時刻に自動で開始）
- 休憩時間（複数登録できます）
- 状況（●）の色、操作キー

## 計画の入力

- **前もって入力する**：「📅 計画」でカレンダーを開き、日付をクリックして各ラインの計画数量を入力します。「この計画を今月の平日すべてに入れる」でまとめて入力できます。
- **当日に入力する**：表の計画数量をクリックするか、テンキー ＊ → 数字 → Enter。

## テンキー操作（初期設定）

| キー | 動作 |
|---|---|
| 1〜5 | ライン A〜E の実績 +1 |
| − → ラインのキー | そのラインの実績 −1（入力ミスの取消） |
| Enter | 作業開始 → 一時停止 → 再開 |
| ＊ | 計画数量の入力（数字＋Enter で次のラインへ、− で1文字消す） |
| ／ を2回（3秒以内） | リセット |

キーの割り当ては設定画面で変更できます。どのラインのキーも同時に受け付けるので、複数ラインで同時に入力できます。
ブラウザではキーボードごとの区別ができないため、テンキーを複数台つなぐ場合は、ラインごとに別のキーを割り当ててください。

## 計算方法

- **現時点目標** = 実稼働時間 ÷ 1個あたりの時間（小数点以下は切り捨て、計画数量が上限）
  - 実稼働時間には休憩時間と一時停止中の時間を含めません。
- **差異** = 実績 − 現時点目標（不足分は ▲ で表示）
- **進捗率** = 実績 ÷ 現時点目標
- **状況**：🟢 100%以上 / 🟠 90〜99.9% / 🔴 90%未満
- **終了時間** = 作業開始時刻 ＋ 計画数量 × 1個あたりの時間（間に入る休憩時間も加算）
  - 作業開始前は設定の作業開始時刻から、開始後は実際に開始した時刻から計算します。
  - 下の小さい「予測」は、今の実績から残りを作り終える見込み時刻です。

## リセット

- **24時を過ぎると**、実績・作業時間・計画数量がすべてリセットされ、新しい日の計画がカレンダーから読み込まれます（未入力の日は 0）。
- **リセット** ボタン（またはテンキー ／ ×2）では、実績と作業時間を消去します（計画数量と設定は残ります）。

データはこのパソコンのブラウザに保存されるため、画面を再読み込みしても残ります。
