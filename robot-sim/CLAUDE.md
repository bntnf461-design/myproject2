# robot-sim — AI（Claude Code）向けの作業メモ

社内用 6軸ロボットシミュレーター。ブラウザで `index.html` を開くだけで動く（ビルドなし・ES モジュールなし・外部 CDN なし）。
`file://` で開くため、JS はすべて classic script で `window.RS` に機能を足していく形にする（import/export は使わない）。

## ユーザーからよく来る依頼と、触るファイル
| 依頼 | 触るファイル |
|---|---|
| ○○用のハンドを追加・変更 | `js/tools.js` の `RS.TOOLS`（必要なら `RS.WORKS` も）。形状はツール座標（Z＝フランジから外向き、原点＝フランジ中心）で作る。`probes`（干渉チェック点）と `approach` を忘れない。 |
| ロボットのプログラムを書いて／直して | `programs/` に実機形式（.JBI / .LS）で置く。下の「プログラムを書くとき」を守る。書いたら `node tests/prog.test.js` で文法チェック（programs/ の全ファイルが検査される）。 |
| 機種を実機に合わせる | `js/robots.js` の `dims` `lim` `vmax` `pulse`。数値は根拠（取扱説明書など）をユーザーに確認する。推測で実機名の数値を入れない。 |
| 命令を増やす | `js/program.js`（parseY / parseF に解析を追加）→ `js/interp.js`（実行）→ `js/ai.js` の LANG（AI に教える命令一覧）→ README の命令一覧 → `tests/prog.test.js` |
| 見た目 | `js/model.js`（関節の階層は `kinematics.js` の `fkKin` と必ず一致させる）、`js/look.js`（建屋・床・質感・画質）、`css/app.css` |

## プログラムを書くとき（安川 INFORM／ファナック TP）
- 座標：ロボット座標、X 前・Y 左・Z 上（mm）。姿勢 R = Rz·Ry·Rx（安川 Rx/Ry/Rz、ファナック W/P/R）。ツール真下向き＝(180, 0, 0)。
- セル（標準）：供給台 中心 (950, 750)、排出台 中心 (950, -750)、上面 Z=450。板ガラス 600×400×5mm（上面 Z=455）。
- セル（実機ライン、`js/cell.js` の `RS.LINE`）：架台でベース面は床から 600mm（推定）。正面（X+）にコンベア（X=1200 から X+ へ流れる、置き場 X=1700・Y=0、上面 Z=250）。後ろ（X−2100）に直進ラック、左（Y+2150）に曲進ラック。ガラス 1000×750×4mm。ハンド glassV（TCP 240mm、バネ 20mm）。入出力：IN#(2) 直進ラック有、IN#(3) コンベア置き場有、IN#(4) 吸盤接触、IN#(5) 曲進ラック有、OT#(2) 置き完了。押し当ては `MOVL … UNTIL IN#(4)=ON`。
- ガラス用 4吸盤ハンドの TCP はフランジから 170mm（吸盤面）。吸着するには 4 つの吸盤面がガラス上面 ±4mm にあること。
- 入出力：安川 OT#(1)=ハンド、IN#(1)=保持確認、IN#(2)=供給台ワーク有、IN#(3)=排出台ワーク有。ファナック RO[1]=ハンド、RI[1]=保持確認、DI[1]=供給台ワーク有、DI[2]=排出台ワーク有。
- アプローチは真上 100mm 以上 → 直線で下ろす。ハンド出力の後は必ず確認入力を WAIT。速度は控えめ（関節 50% 以下、直線 500mm/s 以下）。
- 位置：JBI は `///RECTAN` の `C00000=X,Y,Z,Rx,Ry,Rz`、LS は `P[n]{ GP1: UF : 0, UT : 1, CONFIG : 'N U T, 0, 0, 0', X = … }`。`programs/GLASS_PICK.*` が見本。
- 実機に入れる前提のファイルには、確認が必要な点（UF/UT、速度、未確認の位置）をユーザーに必ず伝える。

## 関節角の向き（重要）
- 画面・プログラムの関節角は `robots.js` の `sign[]` を掛けたメーカーの向き（初期値：B/J5 反転、ツール下向き＝-90°）。新しく位置を書くときは直交（cart）で書く。
- `jointConfirmed` が false の間は、関節位置を実機ファイルに関節値のまま出さない（直交に変換）。この安全策を外さないこと。

## 対象コントローラ
- 安川は **DX200**（ユーザーの実機）。ペンダントの操作・JBI の書式は DX200 に合わせる。JBI は Shift_JIS で書き出す（`RS.encodeSJIS`）。
- ファナックの型式は未確認。

## テスト
```
node tests/kin.test.js
node tests/prog.test.js
node tests/smoke.js      # Playwright（このリポジトリでは require('playwright') がそのまま使える環境を想定）
```
変更後は 3 つとも通すこと。画面を変えたら `SHOTS=<フォルダ> node tests/smoke.js` でスクリーンショットも確認する。

## 守ること
- 実機の安全に関わる動き（干渉チェック、アラーム、入力待ちタイムアウト）を弱める変更はしない。
- 画面の文言は日本語。メーカー名の表示は「安川電機」「ファナック」の文字だけにし、ロゴやマークは使わない。
- 寸法・可動範囲の初期値は「汎用・シミュレーション用」と表示し続ける（実機の仕様だと誤解させない）。
