# ロボットシミュレーター（安川／ファナック）v3.0

社内の教育とプログラム検証に使う、6軸ロボットの 3D シミュレーターです。
`index.html` をブラウザ（Chrome / Edge）で開くだけで動きます。インストールは不要で、インターネットにもつながりません（AI 機能を使うときだけ接続します）。

## できること
| 機能 | 内容 |
|---|---|
| システム切替 | 画面上部で **安川電機 ⇔ ファナック** を切り替えます。外観、軸名（S/L/U/R/B/T ⇔ J1〜J6）、姿勢の表記（Rx/Ry/Rz ⇔ W/P/R）、言語（INFORM ⇔ TP）、ペンダント、ファイル形式（JBI ⇔ LS）が一緒に切り替わります。 |
| 実機のプログラムを実行 | 実機の **.JBI（安川）／.LS（ファナック）** を読み込み、そのまま再生できます。複数ファイル（CALL で呼ぶサブプログラム）もまとめて読み込めます。 |
| 実機用に書き出し | 作ったプログラムを .JBI ／ .LS で書き出せます。書き出す前に、実機に入れるときの注意点を表示します。 |
| プログラム編集 | 一覧で 1 行ずつ編集するか、テキストでまとめて書きます。文法チェック（未定義のラベル・位置・未対応の命令）、元に戻す（Ctrl+Z）、複数プログラムの管理ができます。 |
| AI でプログラム作成 | 「吸着後 1 秒待ってから持ち上げて」のような日本語の指示から、AI がプログラムを作成・修正します。結果は確認してから反映します（「AI」タブ）。 |
| ハンド切替 | 初期は **ガラス用 4吸盤ハンド**。ほかに単吸盤と 2爪グリッパがあり、用途別に切り替えられます。 |
| ペンダント | 実機風のペンダントを表示します。安川はモード切替キー（REMOTE/PLAY/TEACH）、非常停止、START/HOLD、サーボオンレディ＋イネーブルスイッチ、手動速度、補間、試運転（押している間だけ動く）、前進/後退、挿入/削除/修正。ファナックは TP 有効/無効スイッチ、非常停止、デッドマン、SHIFT、F1〜F5（POINT / TOUCHUP など）、STEP、HOLD、FWD/BWD（押している間だけ動く）、COORD、±%、POSN、I/O、操作盤の CYCLE START。「3D画面の上に出す」で、ロボットを見ながら操作できます。 |
| 安全機能 | 干渉チェック、可動範囲、特異点、入力待ちのタイムアウト、非常停止。アラームはリセットで解除します。 |
| 実機合わせ | 「設定」タブで、機種の寸法・可動範囲・パルス係数・ユーザ座標（UF）を実機の値に変えられます。 |

## 使える命令（シミュレーターで実行できるもの）
**安川 INFORM**
`MOVJ` `MOVL`（`VJ=` `V=` `VR=` `PL=`）、`MOVC`（直線で近似）、`IMOV`、`DOUT OT#()`、`PULSE`、`WAIT IN#()`（`T=` 付きも可）、`TIMER`、`*ラベル`、`JUMP *ラベル IF …`、`CALL JOB:` / `JUMP JOB:`、`RET`、`PAUSE`、`SET` `ADD` `SUB` `MUL` `DIV` `INC` `DEC`（B/I/D/R 変数）、`SFTON` / `SFTOF`、`'コメント`

**ファナック TP**
`J` `L`（`%` `mm/sec` `cm/min` `sec` `deg/sec`、`FINE` / `CNT`、`Offset,PR[]` `Tool_Offset,PR[]`、`PR[]` への移動）、`DO[]` `RO[]`（`PULSE` 可）、`WAIT DI[]/RI[]`（`TIMEOUT,LBL[]` 可）、`WAIT (sec)`、`LBL[]`、`JMP LBL[]`、`IF … ,JMP/CALL`（`AND`/`OR` 可）、`CALL`、`END`、`ABORT`、`PAUSE`、`R[]=式`、`PR[]=LPOS/JPOS/PR[]±PR[]`、`PR[i,j]=式`、`UFRAME_NUM` `UTOOL_NUM` `OVERRIDE`、`!コメント`

一覧にない命令は、実行時に飛ばします（「設定」で、飛ばさずに止める設定にもできます）。飛ばした命令は「実行ログ」に出ます。
`CNT` / `PL`（止まらずに通過する動き）は、止まる動き（FINE）として再生します。

## 入出力の割り当て（シミュレーター内）
| 安川 | ファナック | 内容 |
|---|---|---|
| `OT#(1)` | `RO[1]` | ハンド出力（ON＝吸着／閉、OFF＝解放／開） |
| `IN#(1)` | `RI[1]` | ハンド保持確認（ワークを保持していると ON） |
| `IN#(2)` | `DI[1]` | 供給台にワークあり |
| `IN#(3)` | `DI[2]` | 排出台にワークあり |

ほかの入出力は「プログラム」タブの「入出力（I/O）」で手動で ON/OFF できます。教育で、センサー待ちの動きを試すときに使います。

## 実機のプログラムを動かす手順
1. 実機から .JBI（安川）／.LS（ファナック）を取り出します。
   - 安川：ペンダントの「外部メモリ」→「セーブ」で USB メモリに保存します。
   - ファナック：「ファイル」→「バックアップ」で .LS を保存します（ASCII 形式で出すには、コントローラ側の設定やオプションが必要な場合があります）。
2. 「設定」→「機種パラメータ」に実機の寸法・可動範囲を入れます。安川の PULSE 形式を読むときは、1度あたりのパルス数も入れます（機種の取扱説明書に記載の値）。ユーザ座標を使っている場合は UF の値も入れます。
3. 「プログラム」→「読み込み」でファイルを選び（CALL 先も一緒に）、「▶ 再生」で動かします。

## 作ったプログラムを実機で動かす手順
1. 「JBI 書き出し」／「LS 書き出し」でファイルを出します。
2. 実機に読み込みます。
   - **安川**：USB メモリに入れ、ペンダントの「外部メモリ」→「ロード」→「ジョブ」で読み込みます。
   - **ファナック**：.LS をそのまま読めるのは、ASCII プログラムのロード機能（オプション）が入ったコントローラだけです。入っていない場合は、ROBOGUIDE などで .TP に変換してから読み込みます。
3. 実機では必ず次の順で確認します。
   - ツール（TCP）・ユーザ座標・寸法が、シミュレーターの設定と同じか
   - 教示モード・低速で 1 行ずつ（前進 ／ FWD）位置を確認し、必要なら修正（タッチアップ）する
   - オーバーライドを下げて連続運転し、問題がなければ速度を上げる

> シミュレーターの寸法・動き・干渉チェックは近似です。シミュレーターで動いても、そのまま実機で安全に動くとは限りません。最終確認は必ず実機で、上の手順どおり行ってください。

**位置の書き出し形式**
- JBI：パルス係数を設定していれば関節位置を `PULSE`、未設定または直交で教示した位置は `RECTAN`（ベース座標）で書き出します。`RCONF`（形態）は 0 で出すため、実機で読み込んだあとに姿勢（フリップ等）を確認してください。
- LS：関節位置は `J1=…`、直交位置は `X=… CONFIG:'N U T, …'` で書き出します。CONFIG の Flip は「J5 が負なら F」というこのシミュレーターの決まりで付けているため、実機で確認してください。

## AI でプログラムを作る（「AI」タブ）
- **API キーあり**：キーを入れて「AIで作成」を押すと、このページから直接 Claude を呼びます。
- **API キーなし**：「指示文をコピー」→ claude.ai などに貼り付けて送信 → 返ってきた回答を「回答を取り込む」に貼り付けます。社内ネットワークで api.anthropic.com に接続できない場合も、この方法で使えます。
- AI には、ロボットの寸法、セル（台の位置・高さ）、ハンド、入出力の割り当て、今のプログラムが自動で渡ります。
- 結果は文法と届くかどうかをチェックしてから表示します。内容を確認して「プログラムに反映」を押してください。反映後も「元に戻す」で戻せます。

## ハンド・機能の追加（AI に頼む場合）
- ハンドとワークの定義は **`js/tools.js`** にまとめています。「tools.js に ○○ 用のハンドを追加して」と AI（Claude Code）に頼むと、この 1 ファイルの変更で画面に追加されます。
- 機種の初期値は **`js/robots.js`**、AI 向けの作業メモは **`CLAUDE.md`** にあります。

## ファイル構成
```
robot-sim/
  index.html          画面
  css/app.css         見た目
  js/robots.js        機種（安川／ファナック）の寸法・可動範囲・速度
  js/tools.js         ハンドとワークの定義              ← 用途別の変更はここ
  js/kinematics.js    順運動学・逆運動学・直線補間
  js/model.js         ロボットの 3D 形状
  js/program.js       命令の解析、JBI / LS / JSON の読み書き
  js/interp.js        プログラムの実行（ラベル・ジャンプ・CALL・変数・入出力）
  js/ai.js            AI によるプログラム作成
  js/app.js           画面・動作制御・ペンダント
  programs/           実機形式のサンプル（GLASS_PICK.JBI / .LS）
  vendor/three.min.js three.js r128（MIT ライセンス）
  tests/              自動テスト
```

## テスト
```
node tests/kin.test.js     # 逆運動学の往復（約 6000 姿勢）
node tests/prog.test.js    # 命令の解析・JBI/LS の読み書き・インタプリタ
node tests/smoke.js        # ブラウザ総合テスト（Playwright が必要）
```

## 注意
- 寸法・可動範囲・速度の初期値は **汎用の 20kg 級を想定した値** で、特定の機種の仕様ではありません。実機に合わせるときは「設定」で変更してください。
- 逆運動学は「肘が上・前向き」の姿勢だけを使います。肘下・後ろ向きの姿勢、付加軸、円弧（C / MOVC）、通過動作（CNT / PL）は近似か未対応です。
- 干渉チェックは代表点（ハンド・手首・肘・保持ワークの角）だけを見る簡易判定です。アーム同士の干渉は見ていません。
