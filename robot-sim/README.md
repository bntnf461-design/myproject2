# ロボットシミュレーター（安川／ファナック切替）v2.0

社内用の 6軸ロボット 3D シミュレーター。ブラウザで `index.html` を開くだけで動きます（インストール不要、インターネット接続も不要）。

## 起動
- `robot-sim` フォルダごとコピーし、`index.html` をダブルクリック（Chrome / Edge 推奨）。
- three.js は `vendor/three.min.js` に同梱しています。社内ネットワークでも外部に接続しません。

## できること
| 機能 | 内容 |
|---|---|
| システム切替 | 画面上部で **安川電機 ⇔ ファナック** を切替。ロボットの外観・軸名（S/L/U/R/B/T ⇔ J1〜J6）・座標表記（Rx/Ry/Rz ⇔ W/P/R）・プログラム表記（INFORM ⇔ TP）・ペンダント・書き出し形式（JBI ⇔ LS）がすべて切り替わります。プログラムはシステムごとに別々に保存されます。 |
| ハンド切替 | 初期は **ガラス用 4吸盤ハンド**。上部のハンド選択、または「ハンド・セル」タブで用途別に切替（単吸盤、2爪グリッパ）。 |
| ジョグ | 関節（スライダー／±長押し）、直交（ロボット座標／ツール座標、±長押し または 1・10・50mm 送り）。 |
| 位置指定移動 | X/Y/Z と姿勢を入力して **関節移動** または **直線移動**。 |
| プログラム | 関節補間（MOVJ／J）・直線補間（MOVL／L）・ハンド出力・ハンド確認待ち・タイマ。行の挿入／修正／並べ替え／複製／削除、元に戻す（Ctrl+Z）。 |
| 再生 | 連続再生・一時停止・停止・1行実行・繰り返し・オーバーライド。サイクルタイムと完了数を表示。「ワーク自動供給」で排出台を払い出し、供給台に次のワークを置きます。 |
| ペンダント | 安川（サーボON・教示/再生・手動速度・挿入/修正/削除・前進/後退・スタート/ホールド）、ファナック（TP ON・DEADMAN・SHIFT・COORD・POINT/TOUCHUP・FWD/BWD・CYCLE START/HOLD）。 |
| 安全 | 干渉チェック（床・供給台・排出台・ワーク）、可動範囲、特異点、ハンド確認タイムアウト、非常停止。アラームはリセットで解除。 |
| ファイル | JSON 保存・読み込み、安川 **JBI**（直交位置）／ファナック **LS**（関節位置）の書き出し・読み込み。 |

## 吸着の判定（ガラス用 4吸盤ハンド）
- 4つの吸盤すべてがガラス上面に接し（すき間 ±4mm 以内）、ハンドが面に垂直なときだけ保持します。
- 1つでも外れていると保持しません。プログラム中の「確認待ち（WAIT IN#(1)=ON ／ WAIT RI[1]=ON）」が 3 秒でアラームになります。

## ハンドの追加・変更（用途別）
ハンドとワークの定義は **`js/tools.js`** だけにまとまっています。
新しい用途のハンドが必要なときは、AI に次のように依頼してください。

> 「tools.js に、○○（例：ガラス 6吸盤・吸盤間隔 500×300mm・TCP 200mm）のハンドを追加して」

追加されたハンドは、画面上部のハンド選択と「ハンド・セル」タブに自動で並びます。
ロボットの寸法・可動範囲を実機に合わせる場合は **`js/robots.js`** の数値を変更します。

## ファイル構成
```
robot-sim/
  index.html          画面
  css/app.css         見た目
  js/robots.js        機種（安川／ファナック）の寸法・可動範囲・速度
  js/tools.js         ハンドとワークの定義   ← 用途別の変更はここ
  js/kinematics.js    順運動学・逆運動学・直線補間
  js/program.js       プログラム形式・表示・JBI/LS/JSON 書き出し／読み込み
  js/app.js           3D表示・動作制御・UI・ペンダント
  vendor/three.min.js three.js r128（MIT ライセンス）
  tests/              自動テスト
```

## テスト
```
node tests/kin.test.js     # 逆運動学の往復テスト（数千姿勢）
node tests/smoke.js        # ブラウザ総合テスト（Playwright が必要）
```

## 注意
- 寸法・可動範囲・速度は **汎用の 20kg 級を想定した値** で、特定機種の仕様ではありません。
- ペンダントの画面・キー配列は簡略化した再現です。
- 書き出した JBI／LS は、実機に入れる前に ツール番号・ユーザ座標・速度・位置を必ず確認してください。
- 干渉チェックは代表点（ハンド・手首・肘・保持ワークの角）で行う簡易判定です。アーム同士の自己干渉は見ていません。
